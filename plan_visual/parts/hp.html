§2–§4.1 · longphase-s HP 標籤與特徵 F1–F5

long read 上看得到什麼：longphase-s HP 標籤

一條 long read 常常同時跨過 somatic SNV 和附近的 germline het SNP。longphase-s somatic_haplotag 利用 het SNP 把 read 歸到 hap1 或 hap2，再看它有沒有帶 somatic alt，打上 HP 與 PS tag。short-read bulk 資料只有 ref_counts / alt_counts，這裡可以把它們拆到兩條 haplotype 上。

tag 對照 longphase-s 文件

Tag意義在某個 somatic SNV 位點上通常代表本圖條數
HP:1 HP:2read 帶 germline SNP，可歸到 haplotype 1 或 2，但沒有 somatic SNV該 haplotype 上的 ref read5 / 6
HP:1-1 HP:2-1read 帶 somatic SNV，且該 SNV 從 germline haplotype 1 或 2 衍生該 haplotype 上的 alt read4 / 0
HP:3read 帶 somatic SNV，但無法歸到任何 germline haplotype未 phase 的 alt read1
無 tagMAPQ 不足，或 germline SNP 不夠，無法判定未 phase（ref 或 alt 都有可能）3（ref 2、alt 1）
PShaplotype block ID（只有帶 phased SNP 的 read 才有）HP1/HP2 只在同一個 PS block 內有一致的意義PS:1,198,442

tag 字面值：BAM 中寫作 HP:z:1、HP:z:2、HP:z:1-1、HP:z:2-1、HP:z:3。longphase-s 文件

HP1/HP2 只在同一個 PS block 內可比。 不同 block 之間的 phasing 沒有串起來，block 2 的 HP:1 可能對應 block 1 的 HP:2。longphase-s 文件

不能只用 phased read。 benchmark 範例（非 HCC 資料）中，HP:1-1/HP:2-1 的 precision 約 0.98、recall 約 0.63–0.65，HP:3 recall 只有 0.35 longphase-s 文件。也就是約三分之一的 somatic read 沒被 phase，模型必須同時保留 phased 與 unphased（ref_un、alt_un）兩部分 分析推論。

從 HP 標籤萃取的特徵 F1–F5 分析推論

以每個 somatic SNV i、每個 sample s 為單位，在該 SNV 所在的 PS block 內統計。圖示中的數字沿用上方 SNV_A 示意 pileup（F3、F5 為另外的示意）。

F1 haplotype-split counts

ref_h1, alt_h1, ref_h2, alt_h2, ref_un, alt_un

從哪些 tag：ref 來自 HP:1 HP:2 無 tag；alt 來自 HP:1-1 HP:2-1 HP:3 與無 tag。

意義：把 read 依所在 haplotype 拆開。

F2 SNV 所在 haplotype h_i 與後驗 π_i(h)

從哪些 tag：alt read 中 HP:1-1 與 HP:2-1 的比例（例如 Beta(1,1) 先驗）。

意義：SNV 落在哪一條親代染色體上。

F3 haplotype-specific CN C_h1, C_h2

從哪些 tag：ASCAT 給 major/minor；同一 PS block 內 germline het SNP 的 HP1 vs HP2 read depth 比例決定誰是 major（判斷不出來就標 unknown）。

意義：把 total CN 拆到兩條 haplotype。

F4 haplotype-specific VAF

計算：alt_h / (ref_h + alt_h)，h = h_i，由 F1 + F2 得到。

意義：分母只有攜帶這條 haplotype 的 copy，比 total VAF 更直接反映 multiplicity / C_h。

F5 SNV pair 的 read 共現表

從哪些 tag：同一 PS、同一 HP、同時覆蓋 i, j 的 read 上兩位點的 allele → n11, n10, n01, n00。

意義：同一條 read 必定來自同一細胞的同一個 copy，可直接判斷兩個 SNV 是否共存。
