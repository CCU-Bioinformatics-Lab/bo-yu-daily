§1 PhyClone 整體架構

PhyClone 架構：資料怎麼流到一棵樹

PhyClone 只在 M2 碰 read count，之後一路傳遞的都是每個 SNV／cluster 的 [S × G] CCF likelihood grid；tree 狀態本身只有 topology 與 assignment。HP 特徵因此只需要接在兩個位置：M2（per-SNV）與 M5（pairwise）。

M1 輸入驗證與清理 [程式實作]

  • cli.py:448 run → run.py run() → data/pyclone.py:17 load_data；欄位定義在 data/validator/PhyClone_schema.json。
  • 必要欄位 ref_counts, alt_counts, major_cn, minor_cn, normal_cn 等；tumour_content 缺時設為 1.0。移除 major_cn == 0、重複或未出現在所有 sample 的 SNV。
  • 目前完全沒有 haplotype 或 read-level 欄位。

M2 單 SNV 觀測模型 [程式實作]

  • data/pyclone.py:325 get_major_cn_prior 列舉 genotype 假設：SNV 在 CN 變化前（x = 1..major_cn）或之後（mu = 1/total），均勻先驗。
  • utils/math_utils.py:180 / 216 log_pyclone_{beta_}binomial_pdf：三個 population 權重 (1−t, t(1−f), t·f)，對假設做 logsumexp。
  • data/pyclone.py:371 to_likelihood_grid 產生 [S × G]；multiplicity 與時序在此被 marginalize 掉。

M3 Cluster 聚合與 outlier [程式實作]

  • data/pyclone.py:82 _create_clustered_data_point_list：同 cluster 的 SNV grid 直接相加（條件獨立），成為一個 DataPoint。
  • DataPoint.outlier_marginal_prob（data/base.py:34）在 CCF 上均勻積分；compute_outlier_prob（pyclone.py:184）給 outlier 先驗。
  • 有 cluster file 時，推理單位是 cluster。

M4 Tree 結構與 CCF 邊際化 [程式實作]

  • tree/tree_node.py 每個 node 存 log_p、log_r；:59 update_node_from_child_r_vals 算 log_R(v)。
  • tree/utils.py:8 compute_log_S、:28 compute_log_D 以卷積合併 children；tree/tree.py:77 data_log_likelihood 回傳 root 的 log_r。
  • tree 狀態沒有連續 CCF 參數，只有 topology 與 assignment。

M5 TreeJointDistribution [程式實作]

  • tree/distributions.py:124：log_p(tree) = FS-CRP prior + outlier prior + Σ_s logsumexp(root.log_R[s]) + outlier marginal；log_p_one 取 root CCF = 1。
  • 所有 sampler 的分數都從這裡來（smc/swarm/tree_holder.py:74、smc/kernels/base.py:79、mcmc/gibbs_mh.py:60,90、run.py:354）。

M6 推理 [程式實作]

  • run.py:187 run_phyclone_chain、:242 _run_main_sampler：每輪依序 Particle Gibbs（tree 或 subtree）→ DataPointSampler（mcmc/gibbs_mh.py:7）→ PruneRegraphSampler → α 更新。
  • SMC kernel 可選 bootstrap、semi-adapted（預設）、fully-adapted；只操作 topology 與 assignment，不碰 read count。

M7 後處理 [程式實作]

  • process_trace/process_trace.py、process_trace/map.py：選出 MAP tree 或建 consensus tree；CCF 與 clonal prevalence 由 grid 上 max-product 回溯得到。
  • 輸出 newick tree、mutation→clone table、sample prevalence table。

路徑相對於 research/phyclone_research/PhyClone/phyclone/（submodule commit 2738324）。

架構對 HP 特徵的含意 [分析推論]

  • per-SNV 特徵 → M2。給定 SNV 所在 node 的 CCF 後，與其他 SNV 條件獨立，形如 P(obs_i | f_node(i))，可以直接寫進 grid；M3–M7 自動繼承（C2、C3）。
  • pairwise 特徵 → M5。同一條 read 的共現觀測 P(obs_ij | relation(node_i, node_j)) 無法拆成單一 node 的 CCF 函數，所以不能放進 grid，而是在 TreeJointDistribution 加一個 topology 因子（C4）。
  • 因為 M4 的卷積邊際化只接受「每個 node 一條 CCF grid」，C4 刻意只依賴 topology 關係、不依賴 CCF，才不會破壞 M4 的積分結構；也因此 M4、M6 不需要修改。
