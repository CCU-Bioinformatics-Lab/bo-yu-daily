在 PhyClone 中加入 longphase-s 的 haplotype 資訊

PhyClone 目前只看每個 SNV 的 ref / alt read 數與 segment 的 major / minor CN。這份計畫把 longphase-s 打在 long read 上的 HP 與 PS 標籤轉成兩類觀測，分別接進 PhyClone 的兩個位置。

單一 SNV 的 haplotype 觀測 → M2

SNV 在哪條 haplotype、該 haplotype 有幾個 copy、只在該 haplotype 上算 VAF。只改 likelihood grid 的數值，後面的 tree 邊際化、SMC、MCMC 都不用改。

兩個 SNV 在同一條 read 上 → M5

同一條 read 來自同一個細胞的同一個 copy，可以直接排除祖先或分支關係。這個新因子只依賴 topology，加在 joint distribution 上，所有 sampler 自動使用。

§1 PhyClone 整體架構

PhyClone 架構：資料怎麼流到一棵樹

PhyClone 只在 M2 碰 read count，之後一路傳遞的都是每個 SNV／cluster 的 [S × G] CCF likelihood grid；tree 狀態本身只有 topology 與 assignment。HP 特徵因此只需要接在兩個位置：M2（per-SNV）與 M5（pairwise）。

架構對 HP 特徵的含意 [分析推論]

  • per-SNV 特徵 → M2。給定 SNV 所在 node 的 CCF 後，與其他 SNV 條件獨立，形如 P(obs_i | f_node(i))，可以直接寫進 grid；M3–M7 自動繼承（C2、C3）。
  • pairwise 特徵 → M5。同一條 read 的共現觀測 P(obs_ij | relation(node_i, node_j)) 無法拆成單一 node 的 CCF 函數，所以不能放進 grid，而是在 TreeJointDistribution 加一個 topology 因子（C4）。
  • 因為 M4 的卷積邊際化只接受「每個 node 一條 CCF grid」，C4 刻意只依賴 topology 關係、不依賴 CCF，才不會破壞 M4 的積分結構；也因此 M4、M6 不需要修改。

§2–§4.1 · longphase-s HP 標籤與特徵 F1–F5

long read 上看得到什麼：longphase-s HP 標籤

一條 long read 常常同時跨過 somatic SNV 和附近的 germline het SNP。longphase-s somatic_haplotag 利用 het SNP 把 read 歸到 hap1 或 hap2，再看它有沒有帶 somatic alt，打上 HP 與 PS tag。short-read bulk 資料只有 ref_counts / alt_counts，這裡可以把它們拆到兩條 haplotype 上。

tag 對照 longphase-s 文件

Tag意義在某個 somatic SNV 位點上通常代表本圖條數
HP:1 HP:2read 帶 germline SNP，可歸到 haplotype 1 或 2，但沒有 somatic SNV該 haplotype 上的 ref read5 / 6
HP:1-1 HP:2-1read 帶 somatic SNV，且該 SNV 從 germline haplotype 1 或 2 衍生該 haplotype 上的 alt read4 / 0
HP:3read 帶 somatic SNV，但無法歸到任何 germline haplotype未 phase 的 alt read1
無 tagMAPQ 不足，或 germline SNP 不夠，無法判定未 phase（ref 或 alt 都有可能）3（ref 2、alt 1）
PShaplotype block ID（只有帶 phased SNP 的 read 才有）HP1/HP2 只在同一個 PS block 內有一致的意義PS:1,198,442

tag 字面值：BAM 中寫作 HP:z:1、HP:z:2、HP:z:1-1、HP:z:2-1、HP:z:3。longphase-s 文件

HP1/HP2 只在同一個 PS block 內可比。 不同 block 之間的 phasing 沒有串起來，block 2 的 HP:1 可能對應 block 1 的 HP:2。longphase-s 文件

不能只用 phased read。 benchmark 範例（非 HCC 資料）中，HP:1-1/HP:2-1 的 precision 約 0.98、recall 約 0.63–0.65，HP:3 recall 只有 0.35 longphase-s 文件。也就是約三分之一的 somatic read 沒被 phase，模型必須同時保留 phased 與 unphased（ref_un、alt_un）兩部分 分析推論。

從 HP 標籤萃取的特徵 F1–F5 分析推論

以每個 somatic SNV i、每個 sample s 為單位，在該 SNV 所在的 PS block 內統計。圖示中的數字沿用上方 SNV_A 示意 pileup（F3、F5 為另外的示意）。

F1 haplotype-split counts

ref_h1, alt_h1, ref_h2, alt_h2, ref_un, alt_un

從哪些 tag：ref 來自 HP:1 HP:2 無 tag；alt 來自 HP:1-1 HP:2-1 HP:3 與無 tag。

意義：把 read 依所在 haplotype 拆開。

F2 SNV 所在 haplotype h_i 與後驗 π_i(h)

從哪些 tag：alt read 中 HP:1-1 與 HP:2-1 的比例（例如 Beta(1,1) 先驗）。

意義：SNV 落在哪一條親代染色體上。

F3 haplotype-specific CN C_h1, C_h2

從哪些 tag：ASCAT 給 major/minor；同一 PS block 內 germline het SNP 的 HP1 vs HP2 read depth 比例決定誰是 major（判斷不出來就標 unknown）。

意義：把 total CN 拆到兩條 haplotype。

F4 haplotype-specific VAF

計算：alt_h / (ref_h + alt_h)，h = h_i，由 F1 + F2 得到。

意義：分母只有攜帶這條 haplotype 的 copy，比 total VAF 更直接反映 multiplicity / C_h。

F5 SNV pair 的 read 共現表

從哪些 tag：同一 PS、同一 HP、同時覆蓋 i, j 的 read 上兩位點的 allele → n11, n10, n01, n00。

意義：同一條 read 必定來自同一細胞的同一個 copy，可直接判斷兩個 SNV 是否共存。

C0 前處理：從 tagged BAM 到特徵表（PhyClone 外部）

C2 / C3 · M2 單 SNV 觀測模型

C2 / C3：知道 SNV 在哪條 haplotype 之後

兩者都用 F2（SNV 所在 haplotype）和 F3（haplotype-specific CN），但改的是不同的東西：C2 改「有哪些候選答案」，C3 改「怎麼讀 read」。

改什麼read 怎麼用主要效益改動位置
原 PhyClone 程式實作x ∈ {1..major_cn}，加一個「CN 變化後發生」genotype，權重均勻所有 read 合起來算 total VAF—get_major_cn_prior
C2 分析推論候選清單：x ∈ {1..C_{h_i}}，刪掉不可能的 multiplicity不變，仍是 total VAF消除 x／CCF 歧義只改 cn / mu / log_pi 三個陣列
C3 分析推論likelihood 本體SNV 所在 haplotype 的 read 單獨算 VAF，分母不含另一條 haplotype對另一條 haplotype CN 錯誤穩健＋錯誤偵測SampleDataPoint、math_utils.py、to_likelihood_grid

C2：刪掉不可能的 multiplicity

PhyClone 原本只知道 segment 是 major_cn = 3、minor_cn = 1，不知道 SNV 在哪一條，所以 x = 1, 2, 3 都是候選，權重相同 程式實作。在 purity t = 1 下，期望 VAF 是 e_vaf = Σ w·cn·mu / Σ w·cn，w = (1−t, t(1−f), t·f)；三個 x 各自都能找到一個 CCF f 剛好擬合 0.25。如果 alt read 全部是 HP:2-1，而 HP2 在腫瘤裡只有 1 copy，x 不可能超過 1 分析推論。

若 h_i 不確定，π_i(h) 當作假設的先驗權重：log_pi[(h, x)] = log π_i(h) − log(#x | h)，取代原本的均勻 log_pi。C2 不改 SampleDataPoint 結構或 numba likelihood，可以單獨實作與測試。分析推論

C3：只用 SNV 所在 haplotype 的 read 算 VAF

在 CN 正確、模型正確時，C3 比 C2 多得到的資訊很少：haplotype VAF 本身仍有 x–f 歧義（C_h=3、t=1 時，(x=1,f=1)、(x=2,f=0.25)、(x=3,f=1/7) 預測的 haplotype VAF 都是 1/3）。C3 的價值在 CN 有錯 的時候 分析推論。下圖情境：真實 HP1=3、HP2=1，SNV 在 HP1，x=1、f=1，觀察到 total VAF 0.25、HP1 VAF 1/3；ASCAT 把 minor 誤估成 2。

自己調看看 （同一情境：真實 HP1=3、HP2=1，SNV 在 HP1；觀察 total VAF 0.25、HP1 VAF 1/3；t=1）

total VAF 模型

預測 = x·f / (2 + (1+minor)·f) = 0.200
觀察 = 0.250　差距 = −0.050

HP1 VAF 模型（C3）

預測 = x·f / (1 + 2f) = 0.333
觀察 = 0.333　差距 = +0.000

試試：minor=2 時把 x 改成 2、f 調到 0.40，total 模型差距歸零，但 HP1 模型差距變成 +0.111。HP1 模型的預測不受 minor CN 的選擇影響。

likelihood 拆解

read 拆成互不重疊的集合，給定 f 時條件獨立，log-likelihood 相加 分析推論。原本的 log_pyclone_beta_binomial_pdf 是 b ~ BetaBinom(a+b, e_vaf(f)) 對所有 genotype 做 log_sum_exp 程式實作，phased 部分可直接重用它，只換 cn / mu。

log P_i(obs | f) = log Σ_h π_i(h) · [ L_phased(h; f) ]  +  L_unphased(f)

L_phased(h; f)   = BetaBinom(alt_h  | ref_h + alt_h,  e_vaf_hap(f; C_h, x))   # SNV 所在 haplotype
                 + BetaBinom(alt_h' | ref_h' + alt_h', ε)                       # 另一條 haplotype：只有錯誤率
L_unphased(f)    = 原 PhyClone 的 likelihood，使用 ref_un / alt_un、total CN

cn_hap = (1, 1, C_h)     mu_hap = (ε, ε, x / C_h)     # SNV 發生在 CN 變化之前
cn_hap = (1, C_h, C_h)   mu_hap = (ε, ε, 1 / C_h)     # SNV 發生在 CN 變化之後
e_vaf_hap = Σ_k w_k·cn_k·mu_k / Σ_k w_k·cn_k,   w = (1−t, t(1−f), t·f)

第二項是錯誤偵測：另一條 haplotype 上的 alt read 只該來自錯誤，可以用來發現 tag 錯誤或假的 SNV call。實作上新增 HapSampleDataPoint 與 numba 的 log_hap_beta_binomial_pdf，to_likelihood_grid 依資料型別選擇；輸出仍是 [S × G]，M3–M7 不用改 分析推論。C3 的效益要在注入 minor CN ±1 誤差的模擬中評估，不能預期 CN 正確時有明顯提升。

風險：tagging bias。 alt read 走 somatic 分類（HP:x-1 或 HP:3），ref read 走 germline 分類（HP:1/2）；兩條路徑的 tagging rate 不一定相同（longphase-s 文件沒有說明）。若不同，phased 子集中 alt 與 ref 被抽中的比例不同，haplotype VAF 會有偏差。驗證：用純 normal 的 t00_n25 和高 purity subsample 比較 phased 與 unphased 的 VAF 分布；必要時在 C3 加 allele-specific tagging rate 校正參數。分析推論

LOH 邊界：C_{h_i} = 0（該 haplotype 在 tumor 中已丟失）卻仍觀察到 alt read，只能來自丟失前就帶有該 haplotype 的 subpopulation 或 tag 錯誤；第一版不使用 HP 資訊，退回原模型，並列入 C6 診斷。分析推論

C4 · M5 TreeJointDistribution

C4：同一條 read 上的兩個 SNV 告訴我們 topology

同一條 long read 來自同一個細胞的同一個 DNA copy。同一 PS、同一 HP 上兩個 somatic SNV 若被同一條 read 跨過，read 上「有 i／有 j」的組合會直接排除某些 clone tree 關係 [分析推論]。

為什麼和 CCF 無關

禁止哪一格只取決於 node(i) 與 node(j) 的祖先／兄弟關係，不取決於這兩個 node 的 CCF 大小：CCF 只改變允許格之間的比例，不會讓禁止格出現 [分析推論]。plan.md 第一版也讓允許格用均勻或「CCF 無關的固定比例」。

因此這一項可以直接加在 TreeJointDistribution（tree/distributions.py:124）的 log_p、log_p_one、compute_log_p_and_log_p_one 三個函式，只需要 tree.labels（dp idx → node）與 ancestor 判斷，不碰 M4 的 log_R 卷積 [分析推論]。現有三個函式都只是把 prior、outlier 與 root.log_R 相加 [程式實作]。

模型（plan.md §4.5）

log_p_link(tree) = Σ_{(i,j) ∈ PAIRS, 兩者都已指派到非 outlier node}
                     log P(n11, n10, n01 | R(node_i, node_j), ε_link)
R ∈ {same/anc, desc, branch}
P(...) = Multinomial，被禁止的那一格機率是 ε_link，其餘格依照
         ε_link 以外剩下的機率質量分配（第一版用均勻分配，或是 CCF 無關的固定比例）

以 cluster（DataPoint）為單位時，pair 計數可預先相加成 (dp_a, dp_b) → counts，成本 O(K²)，與 SNV 數無關。run.py:187 建立分布時傳入 link_data；cli.py 新增 --pairs-file [分析推論]。

三個邊界情況 [分析推論]

  • 不同 haplotype 的 pair 不列入：SNV 分別在 HP1 與 HP2 時，同一條 read 不可能同時帶兩者的 alt，這種 pair 沒有資訊。
  • SMC 部分樹：只計算兩個端點都已加入樹的 pair；中間目標分布可以隨意設定，只要最後的目標分布正確即可。
  • semi-adapted proposal 不含 link 項：只降低 proposal 效率，不影響正確性，因為 importance weight 用完整的 log_p。若 ESS 明顯下降，第二階段再把 link 項加入 smc/kernels/semi_adapted.py。

限制：amplified 區域會破壞「禁止格」

在 amplified 區域（C_h > 1），i 是祖先時仍然可能出現 n01。第一版只在 C_h = 1 的區域使用 F5，或是把 ε_link 依 C_h 調大。另外 pair 數量取決於 SNV 密度與 read 長度，要先統計 HCC1395 實際有多少 informative pair，再決定值不值得做（§5 Phase 0）[分析推論]。

  1. Tagging bias（C3）。alt read 走 somatic 分類、ref read 走 germline 分類，tag rate 可能不同，會讓 haplotype VAF 產生偏差。Phase 0 要量化。
  2. PS block 太短或在 CN 斷點附近。判定不出 major HP 時退回原模型，並記錄比例。
  3. Subclonal CN。PhyClone 和 C2 都假設 segment CN 是 clonal，而且 reference tumor population 的 CN 是 normal。HP 資訊沒有解決這個假設。
  4. C4 在 amplified 區域。先限制在 Ch=1 的區域。
  5. HP:3 read。第一版放進 unphased alt；比例偏高代表 germline phasing 有問題。
  6. t00_n25 純 normal。只用來估 error rate 與 tagging bias，不放進 tree inference。
  7. 論文主張和本計畫要分開。PhyClone 論文和程式碼都沒有 haplotype 設計。C2–C6 都是新的分析推論，Phase 0–4 驗證完成之前不能寫成「已改善 PhyClone」。
