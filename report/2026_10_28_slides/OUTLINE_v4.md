## P3 標題：「產生樹：SNV 分群，群由小到大形成樹拓樸，再填每個 clone 的 CCF」

- eyebrow：1 · 產生樹
- 圖：三欄，由左到右是第 1、2、3 步。每欄頂部一行規則，下面一張示意圖。全部標「示意」。
  1. SNV 分群（中國餐廳過程）
     - 規則：桌上 SNV 越多，越容易被選；也有機會開新桌。
     - 圖：4 根長條，c1 4、c2 3、c3 2、c4 1。
  2. 形成樹拓樸
     - 規則：群依 SNV 數由小到大加入；新群隨機亂數產生 k，收 k 個還沒有 parent 的群當 child；最大群最後加入，成為 root。
     - 圖：最後的樹 c1 → c2、c3；c3 → c4。c3 收 c4 那條邊旁放 k 標籤：「k＝1，機率 1/2」（上下式分數，F-11）。
  3. 填每個 clone 的 CCF
     - 規則：CCF＝自己＋所有後代。
     - 圖：同一棵樹，每個節點寫「自己｜CCF」。
- 圖下「作者資料的實際結果」列（E-3）：600 個 SNV → 9 群；100 棵樹的 root 都是 SNV 最多的群。
- 頁面文字：只有規則短語與圖上標籤。
- 講稿：
  - 結論：群越大越容易再變大；後加入的群當 parent，所以 parent 的 SNV 數不會比 child 少。
  - 沿著三欄講，一欄講完再講下一欄（S-10）。
  - 開新桌的機會由 α 控制，程式預設 α＝1。
  - k 標籤：c3 加入時，只有 c4 沒有 parent，k 可以是 0 或 1，共 2 種；這次是 1，所以機率 1/2。c2 加入時 k＝0，機率也是 1/2。
  - 論文和程式不同（C-7）：論文寫的是先產生一片均勻的樹林，再接到一個空的共同 root；測試程式卻讓 root 一定是 SNV 最多的群。作者 100 棵樹也是這樣，這和程式吻合，是推論。這種偏向可能讓方法判斷祖先關係時看起來比較準，也是推論。
  - clone 比例每個 clone 機會均等，和群的大小無關。
  - 連回目標：long read 版，分群與 CCF 沿用；樹形偏向請老師決定。
  - 橋接：「樹有了，接著看 read 數怎麼產生」。

## P4 標題：「產生 read 數：每個 SNV 各自隨機亂數產生拷貝數與 read 數，沒有位置也沒有 HP」

- eyebrow：2 · 產生 read 數
- 圖：三欄。
  1. 第 4 步，拷貝數：兩個情況的細胞示意，都是 3＋1（示意）。
     - 突變在拷貝數改變之後：帶突變細胞 4 份中 1 份帶突變。
     - 突變在拷貝數改變之前：沒帶突變細胞 2 份；帶突變細胞是兩種之一，各 1/2：4 份中 3 份，或 4 份中 1 份。
  2. 第 5 步，read 數：細胞組成長條（正常、沒帶突變的腫瘤、帶突變）；一行公式「帶突變 read 比例＝帶突變份數 ÷ 全部份數（依細胞比例加權）」；1000 條 read 的長條，帶突變 k 條（示意）。
  3. 結果：程式只把結果留在記憶體，不寫檔。旁邊畫作者資料集的兩個檔：「read 數表」與「答案檔」。下面一行斜線底：真實位置、read 序列、HP（F-5）。
- 頁面文字：只有圖上的短語。
- 講稿：
  - 結論：同一個 sample 內，拷貝數每個 SNV 各自決定，read 數每個位點各自決定。所以結果沒有位置，也沒有 HP。
  - 拷貝數：這段染色體有幾份，分成較多和較少兩邊。
  - 真實腫瘤的拷貝數改變是一整段染色體的事件，同一個 clone 的突變應該共用。程式每個 SNV 各自決定，這是簡化。作者資料同一群的 17 個 SNV，在同一個 sample 內出現 7 種拷貝數組合。
  - read 數用二項分布產生，像擲 1000 次不公平的硬幣。1000 是作者資料的深度，程式預設是 100。
  - 0.001 是定序錯誤率，只用在完全不帶突變或完全帶突變的細胞。
  - 我們用作者資料手算比例，和資料檔記錄的值相同。作者資料的 purity 是 1.0，不合實際。
  - HP：每條 read 來自兩份同源染色體的哪一份，HP1 或 HP2。程式完全沒有產生。
  - 連回目標：long read 版，這兩步都要重寫。
  - 橋接：「沒有 HP，那它能不能直接當我們的 long read 驗證資料？」

## P6 標題：「改成 long read 版：沿用分群與 CCF，重寫拷貝數與 read 數，新增 HP1／HP2」

- eyebrow：4 · 要改哪裡
- 圖（L-8）：沿用 P2 的藍、橘兩色。一張六列表，每列一步，頂端標籤：沿用、修改、重寫、新增。

  | 步 | 標籤 | 做什麼 | 輸出 | 假設 |
  |---|---|---|---|---|
  | 0 | 新增 | 放真實位置與父母不同的 germline SNP | HP1、HP2 兩份染色體 | 位置照真實基因組 |
  | 1 | 沿用 | SNV 分群 | 群 | 同原程式 |
  | 2 | 修改 | 形成樹拓樸；拷貝數事件放在邊上 | 樹＋事件 | 樹形偏向：待老師決定 |
  | 3 | 沿用 | 填每個 clone 的 CCF | CCF | 同原程式 |
  | 4 | 重寫 | 一段一段的拷貝數；SNV 放在 HP1 或 HP2 | 每個 clone 每段的份數 | 先後由樹決定 |
  | 5 | 重寫 | 產生跨多個位點的 read；加入 HP 標錯 | 每條 read 的 HP 與突變 | purity 小於 1 |
- 圖下一列（L-9）：「目前進度：流程已設計，程式尚未實作。下一步：用一棵小樹產生帶 HP 的模擬資料。」
- 講稿：
  - 結論：分群與 CCF 沿用，樹和答案檔格式跟作者一致，評分程式可以共用。
  - germline SNP：正常細胞就有、父親和母親版本不一樣的位點。read 靠它分到 HP1 或 HP2。
  - 拷貝數事件可以放在 root 的邊（所有腫瘤細胞都有），也可以放在下層的邊。同一條邊上，突變和拷貝數誰先誰後，要先定規則。
  - 突變消失：後代丟掉帶突變的那一份，突變就消失。所以要知道丟掉的是 HP1 還是 HP2。LOH 也有份數不變的 2＋0。
  - HP 標錯分兩種：phasing 區塊的邊界（區塊之間接不起來），以及區塊內 HP1、HP2 對調。
  - 請老師決定：樹形偏向要修正，還是保留以便和作者資料比較？我們的提案：兩套都產生。
  - 回到老師的問題：模擬資料怎麼產生，就是這五步，加上新增的一步。
