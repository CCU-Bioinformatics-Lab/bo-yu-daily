這頁是第 3 步放事件的後半：放 copy number。結論：同一種 gain，先後不同，帶 SNV 的份數就不同，之後看到的 read 比例也不同。allele 是同一段染色體的兩個版本，一份來自父親、一份來自母親，這裡分成爸爸的 copy number 和媽媽的 copy number，圖上簡寫成「爸」和「媽」。程式裡這兩份只叫 A 和 B，不分父母；這裡把 A 當成爸爸那份，方便講。copy number 是有幾份；multiplicity 是幾份帶 SNV。看左邊 SNV6，它在 c2：先 SNV，再爸爸那份 gain，複製出的爸爸那份也帶 SNV，multiplicity 2。中間 SNV8，它在 c3：先爸爸那份 gain，再 SNV，只有一份帶 SNV，multiplicity 1。同一 clone、同一位置的事件，程式隨機排序。事件有爸爸 gain、媽媽 gain、兩邊都 gain、媽媽 loss、cnLOH 和 WGD；cnLOH 是丟掉媽媽那份、爸爸多一份，總份數不變。WGD 和 cnLOH 也一樣，在 SNV 之後發生，帶 SNV 的份數就增加。程式不丟帶 SNV 的爸爸那份，所以後代都保留 SNV。一個位置最多一個 copy number 事件，WGD 另計；truncal 事件在 c1，subclonal 事件在 c1 以下。再看最右邊這棵樹：SNV6 的 gain 放在 c2，SNV8 的 gain 放在 c3，都是 SNV 出生的那個 clone。程式不會把這個位置的 copy number 事件放到後代，例如 c4，所以帶 SNV 的細胞 multiplicity 都一樣。c2 旁邊放的是左邊 SNV6 的最後狀態：兩份帶 SNV 的爸爸加一份媽媽。c3 旁邊放的是中間 SNV8 的最後狀態：一份帶 SNV 的爸爸、一份不帶的爸爸加一份媽媽。以上是程式行為。真實腫瘤是一整段一起變；程式每個位置各自決定，這是我們的推論：它是簡化。狀態定好了，下一步把 clone 混成一個 sample。
