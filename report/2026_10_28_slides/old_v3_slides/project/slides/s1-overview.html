上次老師問：模擬資料怎麼產生？結論先講：PhyClone 的模擬分五步，先產生樹，再用樹產生 read 數。接著從左到右看。左邊藍色大方框是 fscrp.py，負責前三步。第一步，SNV 分群。第二步，形成樹拓樸。第三步，填每個 clone 的 CCF。clone 就是帶有同一組突變的一群腫瘤細胞。樹做好之後，看中間虛線框，這是樹交給下一個程式的資訊，只有兩樣：每個 SNV 屬於哪個 clone，以及這個 clone 的 CCF。再往右是橘色大方框 sim_data_on_tree.py，負責後兩步。第四步，每個 SNV 各自隨機亂數產生拷貝數與帶突變的份數；這一步不用樹的資訊。第五步，把中間傳來的 CCF 和第四步的拷貝數合起來，算出帶突變 read 的比例，再隨機亂數產生 read 數。接下來用一個 10 個 SNV 的小例子一步一步看，這個例子是示意。先看第一步：10 個 SNV 怎麼分成 4 群。
