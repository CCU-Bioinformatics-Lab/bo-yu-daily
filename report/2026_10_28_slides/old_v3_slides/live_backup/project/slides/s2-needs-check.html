結論先講：拿我們的五項需求來對，PhyClone 模擬只符合真值樹這一項，所以不能直接用。先說明需求：我們只用 long read 模擬資料。表格左欄五項依序是：read 要長到跨過多個位點；要有答案樹；每條 read 要有 HP；一條 read 上要能同時看到兩個突變，也就是同 read 共現；拷貝數要跟著 clone 走，因為拷貝數改變是某個 clone 的事件，會遺傳給後代。大家看表格中間這欄，只有綠色的真值樹是有，因為樹和 CCF 都存下來了。其他四個紅色的無，每一個我們都在程式原碼裡找到原因。long read：程式根本不產生 read。HP：這裡先解釋一個詞，父親和母親版本不一樣的位點，也就是 germline SNP，是正常細胞就有的差異位點，read 靠它分到 HP1 或 HP2，而程式完全沒有產生這種位點。老師可能會問：第四步不是已經分了較多和較少兩邊嗎？請看右下這張圖。有分，但每個位點各自重分，所以位點 1 和位點 2 的較多那邊，不一定是同一份染色體。同 read 共現：每個位點各自隨機亂數產生，也沒有真實位置。拷貝數：每個 SNV 各自隨機亂數產生，不成段，同一個 clone 的突變也不共用。不能直接用，那有哪幾條路可以走？
