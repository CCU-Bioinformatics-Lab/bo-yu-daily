結論：SNV 分群和填每個 clone 的 CCF 沿用，拷貝數和隨機亂數產生 read 數重寫，最前面新增一步。這是做法 C 的流程。上面的藍色帶和橘色帶跟第 2 頁兩個程式方框的顏色一樣：藍色是產生樹，橘色是產生 read 數。每格頂端的標籤寫著沿用、修改、重寫或新增。最左邊灰框的新增：先放真實位置和 germline SNP，定出兩份完整的染色體。綠色沿用的兩格不動，樹和答案檔格式跟作者一致，評分程式可以共用。紫色修改的形成樹拓樸，修正版和原版各產生一套，邊上放拷貝數事件。修正版的意思是：child 可以比 parent 大，不再有原版的大小偏向。偏向要不要修，請老師決定。紅色重寫的拷貝數：事件綁在邊上以後，沒帶突變的腫瘤細胞可能來自好幾個 clone，份數各不相同，三群算法不再成立，要每個 clone 分開加總。事件在突變的後代時，不同後代的帶突變份數不同，這符合生物；後代如果丟掉帶突變的那份，突變就消失，這正是作者突變丟失資料要模擬的情況；所以較少那邊要允許 0 份，也就是 LOH。最右邊隨機亂數產生 read 數那格放區間斷點，因為它來自 read 長度和分 HP 的工具，不是基因組本身的性質。最下面是進度：流程設計好了，程式還沒寫。
