結論：群由小到大加入，後加入的當 parent，所以 parent 的 SNV 數不會比 child 小。先看最上面這行規則。群照 SNV 數由小到大一個一個加入。每加入一群，先數現在有幾群還沒有 parent，再隨機亂數產生 k，從 0 到這個群數，每個值機率一樣，然後隨機挑 k 群接到底下。最大群最後加入，一定全接，成為 root。舉個例子，大家看第二行：10 個 SNV 分成 4 群，c4 一個、c3 兩個、c2 三個、c1 四個。這是示意，不是作者資料。再看下面四格。有分數的格子，代表這一步由隨機數決定。第 1 格，c4 最小，前面沒有群，直接放入，結果固定。第 2 格，c3 加入，這時只有 c4 沒有 parent，所以 k 可以是 0 或 1，共 2 種，這就是分母 2；這次隨機產生的 k 等於 1，是其中 1 種，這就是分子 1，所以機率是 1 除以 2，結果把 c4 接到底下。第 3 格，c2 加入，這時只有 c3 沒有 parent，k 一樣可以是 0 或 1，分母還是 2；這次隨機產生的 k 等於 0，也是 2 種裡的 1 種，所以分子是 1，不是 0；機率也是 1 除以 2，結果都不接。第 4 格，c1 最大、最後加入，結果固定，一定全接，成為 root。作者真實資料的 600 個 SNV、9 群也照同樣規則建樹。我們重算了作者 100 棵樹：root 全是最大群，每一條邊都是 parent 不小於 child。樹有了，接著看每個 clone 的比例。
