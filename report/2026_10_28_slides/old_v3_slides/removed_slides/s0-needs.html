判斷能不能用之前，先列需求：我們要的模擬資料要有五樣東西。從左邊看起。第一張，long read：一條 read 夠長，能跨過好幾個位點。第二張，真值樹：就是模擬時設計好的答案樹，有它才能評分。第三張，HP：每條 read 標出它來自兩份同源染色體的哪一份。要注意，HP 只在同一段可以接起來的區間內有意義；HP1 也不等於父親那一份，每個區間各自標號。第四張，同 read 共現：一條 read 上同時看到兩個體細胞突變，就是紅點這兩個。第五張，拷貝數跟著 clone 走：這是生物假設。拷貝數改變是某個 clone 發生的事件，會遺傳給後代，所以同一個 clone 在不同 sample 的拷貝數應該一致。最下面這行：我們只用 long read 模擬資料，short read 資料集都不用。這張清單在第 12 頁會逐條對照。PhyClone 是我們要改的基線。它的模擬程式最接近我們要的，答案檔格式也可以共用。所以先拆它。
