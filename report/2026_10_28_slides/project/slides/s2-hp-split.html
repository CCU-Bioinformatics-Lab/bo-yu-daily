結論：真實腫瘤的 clone 樹上，同一個 clone 的 SNV 會分在 HP1 和 HP2 兩條 haplotype，所以我們的模擬真值樹也照這樣設計。先看左邊，這是 GIAB 的胰臟癌細胞株 HG008。樹是用 8 株單細胞衍生 clone 排出來的，圖上把原始編號簡化成 1 到 8：1＝3E4、2＝2D6、3＝2E6、4＝SC6、5＝SC9、6＝SC24、7＝SC14、8＝SC28。圖上每個 clone 都寫成 h 加編號：h1 是 truncal；h3 是 1 號；h4 是 2、3、4 號；h7 是 5、6 號；h8、h9 是 7、8 號；h2、h5、h6 是它們之間共有突變形成的 clone。這些 clone 也就是先分離單一細胞、培養成一群，再用 PacBio long read 整群定序。我們再用另一批 119 顆單細胞檢查每條枝，這些細胞數圖上不放，口頭補充即可。truncal 119 顆全部都有；1 號最早分出去，其他 7 株有一段共同枝；5 到 8 號這一群有 48 顆，7、8 號有 16 顆，而且全部在那 48 顆裡面，所以樹的分枝在單細胞層級也對得上。每個節點旁的藍色數字是 HP1 上的 SNV 數，橘色是 HP2。HP1、HP2 的方向由同一位病人正常組織的組裝序列決定。每株 clone 的 PacBio long read 本身已經把 SNV 定相，我們用同一段定相裡的 germline 位點對照組裝序列，把方向統一；只算兩條 haplotype 都在的區域。大家看，九個節點每一個都有藍有橘：深藍的 h1，也就是 truncal，是 2,404 比 2,490；青色的 h6 是 34 比 55；連只屬於單一株的 h8、h9 也一樣。h4、h7 是幾株合併，數字是加總。這個判讀和 bulk ONT long read 的獨立判讀有 99.7% 一致。h6 這群在 bulk 約佔 0.14，和單細胞的 16／119 對得上。所以不只 truncal，每個 subclone 的 SNV 都分在兩條 HP。再看右邊，這是我們的模擬真值樹，顏色和左邊對應：c1 對到 h1，c3 對到 h6。每個 SNV 都指定在 HP1 或 HP2，c1 和 c3 兩條都有。c2、c4 只放在一條，是為了之後搭配 copy number 事件。這個設計讓模擬器能產生 long read：每條 read 先決定來自哪個 clone、哪條 haplotype，只有那條 haplotype 上的 SNV 才會出現在 read 上。要注意，HG008 是細胞株在培養中的演化，這頁只證明 HP 拆分會發生，不代表病人腫瘤的比例。copy number 事件、突變遺失與低 CCF clone，之後各用一頁，用同樣的左右對照來證明。下一頁先看 HP gain：某一條 HP 多一份時，上面的 SNV 會怎樣？
