結論：建樹工具只該拿到左邊的 read count 與 copy number；右邊的樹和 SNV 歸屬是評分用的答案。左邊這張表用的是同一位病人 SIM004 的示意值，每個 SNV 一列：alt、depth、爸爸和媽媽的 copy number、purity。SNV6 那一列就是上一頁從罐子抽出來的 107 和 683。copy number 是腫瘤細胞的平均，所以 SNV6、SNV8 這種只有部分 clone 有 gain 的位置，會出現 1.29、1.51 這種小數。右邊是同一棵示意樹，枝旁是 SNV 屬於哪個 clone，節點旁是 clone 比例。要注意，程式輸出的表把 SNV 所屬 clone 欄，和 CCF 欄，也就是帶這個 SNV 的腫瘤細胞比例，也寫在同一個檔裡，給建樹工具前要先拿掉。實際輸出的檔裡，每個 SNV 有座標、REF 和 ALT、兩個 allele 的 copy number、purity。座標依染色體長度隨機撒在 chr1 到 chr22，REF 和 ALT 也是隨機選的，不對應參考序列。回到老師的問題：模擬資料就是最下面這五步產生的，定參數、建樹、放事件、混合 clone、產生 read count。每一步的程式位置我都核對過，也重跑出一樣的結果。CONIPHER 只產生 short read 的計數，沒有 haplotype。接下來看怎麼沿用這五步，改成 long read 版的模擬程式。
