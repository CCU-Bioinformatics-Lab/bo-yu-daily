結論：VAF 由細胞組成、copy number 和 multiplicity 一起決定；read count 只是在 VAF 上加隨機性。數字都是用 SIM004 的 purity 0.59、coverage 625 手算的示意，depth 和 alt 是舉例的亂數值。先看左邊。Dirichlet 把總和固定的比例隨機切成幾份，乘上 purity 就是腫瘤 clone 的比例；normal 是 1 減 purity。下面的蛋糕圖是比喻：把 purity 0.59 想成一個蛋糕，Dirichlet 是一把刀，隨機切成幾塊，每塊給一個 clone。程式的 Dirichlet 參數全是 1，所以每一種切法的機率都相同，不偏向任何 clone。例子裡 c1、c2、c3、c4 都在樣本中，四個加起來等於 purity 0.59。c1 的 12% 是只帶 truncal SNV、還沒長出後代突變的細胞。程式先放入全部 leaf，再從其他 clone 隨機補到 3 到 8 個，所以內部節點 c1、c3 都可能被抽到。再看中間，只用 SNV6 算一次，用彈珠來數。想像樣本有 100 個細胞，每個細胞在這個位置的每一份 copy 是一顆彈珠。normal 41 個細胞，每個 2 顆灰彈珠；c1、c3、c4 也是每個 2 顆。SNV6 只在 c2。c2 先有 SNV、再爸爸 gain，所以每個細胞有 3 顆，其中爸爸那 2 顆帶 SNV，是紅色。把全部彈珠倒進罐子：總共 217 顆，這就是分母，總 copy number。紅色 34 顆，也就是 17 個 c2 細胞乘 2 顆，這就是分子，帶 SNV 突變的 copy 數。VAF 就是罐子裡紅彈珠的比例，34 除以 217，約 0.16。從圖上看得出兩件事：normal 的灰彈珠很多，會把 VAF 拉低；c2 每個細胞多一顆，分母也跟著變大。上一頁的先後決定每個 c2 細胞有幾顆紅彈珠，這就是它改變 VAF 的地方。最後看右邊，還是同一個罐子。定序就像從罐子抽彈珠：每條 read 抽 1 顆，看完放回。先決定抽幾次，這就是 depth。SIM004 的 coverage 是 625；這個位置的彈珠比一般位置多，分母 2.17 大於 2，所以 depth 調高，Poisson 產生 683 次。再看抽到幾顆紅的：每次抽到紅彈珠，也就是抽到 alt read 的機率，就是中間算出來的期望 VAF 0.16；程式直接把這個 VAF 當成二項分布的機率。抽 683 次，產生 107 次紅，這就是 107 條 alt read，其餘 576 條是 ref。同一個罐子抽兩次，alt 數也會不同，這就是 read count 的隨機性。程式只產生 read count，不產生 read 序列。最後，程式交出哪些檔？
