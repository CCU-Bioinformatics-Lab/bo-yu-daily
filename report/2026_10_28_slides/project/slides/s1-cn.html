這頁是第 3 步放事件的後半：放 copy number 事件。結論：同一個 clone 裡，copy number 事件和 SNV 隨機排先後，先後決定 multiplicity。最上面這行是規則，骰子代表隨機。allele 是同一段染色體的兩個版本，這裡分成爸爸和媽媽的 copy number；程式裡只叫 A 和 B，這裡把 A 當成爸爸，方便講。copy number 是有幾份，multiplicity 是幾份帶 SNV。先看上排左邊 SNV6，它在 c2：先 SNV，再爸爸 gain，複製出的爸爸那份也帶 SNV，multiplicity 2。右邊 SNV8 在 c3：先 gain 再 SNV，multiplicity 1。每張卡右邊的小演化樹標出這個事件放在哪個 clone：程式隨機挑一個 subclone，左卡挑到 c2，右卡挑到 c3，黑框和「事件」標籤就是被挑到的那個。事件有爸爸 gain、媽媽 gain、兩邊都 gain、媽媽 loss、cnLOH 和 WGD；一個位置最多一個 gain 或 loss，WGD 另計。再看下排的 WGD，它也是 copy number 事件，會讓每個位置的爸、媽和 SNV 份數都乘以 2，灰底就是加倍的 clone。WGD 參數是無時不放，SIM004 就是這種。clonal 時放在 c1，全部腫瘤 clone 加倍。subclonal 時，程式從虛線圈的 subclone 裡只挑 1 個，不含 c1，骰子代表這個隨機選擇；這裡舉例挑到 c3，所以只有 c3 和後代 c4 加倍，c2 不變。最右邊的表：WGD 和 SNV 也隨機排先後。以 c1 為例，SNV 先發生，multiplicity 2；WGD 先發生，multiplicity 1。purity 0.59 時，VAF 是 0.37 和 0.19，沒有 WGD 是 0.30。真實腫瘤是一整段一起變，程式每個位置各自決定，這是我們的推論：它是簡化。狀態定好了，下一步把 clone 混成一個 sample。
