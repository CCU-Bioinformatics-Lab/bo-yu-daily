結論：long read 版的模擬程式不從零寫，而是沿用 CONIPHER 生成器的五步骨架，只改寫兩步。上面一列是前面講完的 CONIPHER 五步，再加上輸出；下面一列是我們的 long read 版 longbulksim，同一欄就是同一步。中間的標籤告訴大家每一步怎麼借：灰色是擴充或修改，綠色是沿用，紅色是新寫。先看最左邊的定參數：兩邊定的是同一組參數，也就是 clone 數、SNV 數、purity、coverage、gain／loss 比例和 WGD，每個都是範圍內的隨機值。這裡先說明一點：目前程式還是用固定值，每次模擬的參數都一樣；改成範圍內隨機值是我們接下來要做的。建樹一樣隨機產生，改成照 TRACERx 的樹形比例產生直線或分岔樹。第一個新寫的是放事件：每個 SNV 除了放在哪條枝，還要指定在 HP1 還是 HP2；copy number 事件也要指定是哪條 HP 多一份或少一份。這樣 SNV 的份數就由事件的先後自然決定，不用另外設定。混合 clone 完全沿用，比例乘上 purity。第二個新寫的是產生 read：CONIPHER 每個位點各自產生 depth 和 alt，long read 版改成一條一條產生 read，每條先決定來自哪個 clone、哪條 HP、多長，同一條 read 會蓋到好幾個 SNV，所以會有共現資訊。輸出沿用 PhyClone 的格式，再多兩個檔：HP 計數和 SNV 共現表。程式有測試確認共現遵守樹、計數符合期望 VAF。新寫的這兩步引進了 SNV 分 HP、HP gain 這些 CONIPHER 沒有的事件。它們在真實腫瘤裡真的會發生嗎？下一頁用 GIAB HG008 的資料來回答。
