結論：VAF 由細胞組成、copy number 和 multiplicity 一起決定；read count 只是在 VAF 上加隨機性。數字都是用 SIM004 的 purity 0.59、coverage 625 手算的示意。先看左邊。Dirichlet 把總和固定的比例隨機切成幾份，乘上 purity 就是腫瘤 clone 的比例；normal 是 1 減 purity。程式先放入全部 leaf，再從其他 clone 隨機補到 3 到 8 個，內部節點也可能被選。例子補了 c3，沒選到 c1。再看中間。VAF 是帶 SNV 的 read 佔全部 read 的比例。SNV1 在全部腫瘤細胞都有，purity 0.59 除以 2 份，VAF 約 0.30。SNV6 只在 c2，比例 0.22，但有 2 份帶 SNV，所以 VAF 是 0.20。SNV8 在 c3 和 c4 都有，比例加起來 0.37，可是只有 1 份帶 SNV，總份數又變成 3，所以 VAF 只有 0.16。上一頁的先後，就這樣改變 VAF。最後看右邊。SIM004 的 coverage 是 625，Poisson 產生 SNV1 的 depth 618，二項分布產生 181 條 alt read。份數多的位置，depth 也調高。程式只產生 read count，不產生 read 序列。最後，程式交出哪些檔？
