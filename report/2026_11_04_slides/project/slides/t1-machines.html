這頁列出 diplosim 模擬的 long read bulk 資料，每個 SNV 輸出的全部資訊。左邊是 SNV1 位置的 read 示意，read 的排法是示意：最上面是 depth，也就是 ref 加 alt 的條數；中間是兩條 allele，allele A 是 HP1、allele B 是 HP2，各 1 份，SNV 在 allele A；下面三組 read，藍色是 HP1，橘色是 HP2，灰色是分不出 HP 的 unphased；紅點是帶 SNV 的 read，白點是 ref。右邊是輸出的一列，SNV1 實際輸出的數字。上面四列兩台機器都有：depth ref 36、alt 21，allele A、B copy number 1、1，帶 SNV 的份數 1，clone trunk、CCF 1.0。下面四列是 diplosim 新增的：真值，SNV 在 allele A，也就是 HP1；HP1 的 read ref 0、alt 19；HP2 的 read ref 27、alt 0；unphased 的 read ref 9、alt 2。最下面是真值樹，diplosim 也會另外輸出，這週先不驗，之後再驗。接下來看怎麼檢查這些輸出接近真實的 long read。
