# 大綱 v1 審查摘要（P-1，2026-11-01）

審查者：邏輯漏洞審查者、生物資訊教授（兩個 subagent，各自讀完整大綱與來源檔）。

## 兩位都指出的問題

1. **主結論說得太滿（p6、p9）。** 「低 purity 差距主要來自量測端，不在 diplosim」的證據不足：
   - ⑤、⑥ 用到的 c、偵測曲線，有一部分是從 holdout 樣本量出來的（t10、t40 曲線就是那兩個樣本）。
   - ③ 改成範圍抽樣後區間變寬，「落在區間」比較容易。
   - t20、t10 項數的大跳升來自 ③ 與 ⑥；④、⑤ 沒有增加項數。
   - 剩下的失敗（split alt、SNV 在 depth 較少那條 HP）都和 HP 有關，正是 PhyClone HP 擴充要用的特徵。
   → 建議：標題縮小成「VAF 與 call 數的差距主要來自 ClairS 與 purity 換算」，HP 類差距列為未解決；主因說法標〔推論〕。
2. **purity 寫法混用（p5、p7）。** 10-30 PPC 把 t50 寫成 purity 1，大綱寫 0.97。→ 統一寫「nominal（tumor reads 比例）／換算細胞 purity」，並寫出 0.97 與 ψ 3.06 的來源和敏感度（ψ 2.73 時差約 10%）。
3. **p7 統計量數前後不一（14 項、13 項）**，而且 5/14 → 12/13 中間跳過 v2 的 8/13。→ 建議 p7 併入 p8，一律用 13 項、從 v2 起算。
4. **黑話太多（T-5）**：HP0、split alt、minor HP、mistag、base error、φ、c、PPC、holdout、t50 等。→ 用一張 read 示意圖一次解釋 HP1／HP2／HP0、mistag、base error。
