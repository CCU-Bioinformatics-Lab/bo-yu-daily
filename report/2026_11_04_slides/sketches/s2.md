## p5 t2-validation：需求分兩組

```
[HCC1395 資料] 真值：沒有 clone 樹，只比數值 | 讀長：ONT long read | 輸入：ClairS somatic SNV、各 HP read 數 | 公開真實資料，無生成程式   ← L-3
┌ 驗資料像不像（藍）────────────┐ ┌ 驗樹能否重建（橘）──────────────┐
│ [read 圖] 需求：只用 long read │ │ [樹圖] 需求：要有真值 clone 樹     │
│           能讀出 HP1／HP2      │ │                                    │
│ HCC1395 ONT ✓long read ✓HP  先用│ │ HCC1395            ✗ 沒有 clone 樹 │
│ TRACERx 統計 ✗ short read  排除 │ │ diplosim 真值樹 ✓測 PhyClone        │
│                                │ │                 ✗不證明模擬像真實  │
│                                │ │ [?] 驗樹的真實資料：還沒決定（虛線）│
└────────────────────────────────┘ └────────────────────────────────────┘
```

- 誰和誰比：候選資料對兩組需求。哪裡沒有：驗樹沒有合格的真實資料。結論：HCC1395 只用在驗資料。
- 來源：HCC1395 沒有已知 clone 樹、只驗定序資料〔R6 §問題〕；ClairS PASS ∩ HC、longphase haplotag〔R6 §2–3〕；TRACERx 排除（short read）〔memory long-read-only validation；OUTLINE p1〕；diplosim 真值樹只測 PhyClone〔M，議題三〕。
- 「公開真實資料」：SEQC2 HCC1395 ONT（R6 資料段）。頁面不寫 SEQC2，避免多一個縮寫。
- 與大綱差異：把講稿要講的「diplosim 自己的真值樹」放上頁面當一列候選，因為 S-11 規定講稿只講畫面上有的。

## p6 t2-purity：5 種混合比例＋流程

```
read 來源比例（nominal）                       tumor 細胞比例   ┌ read 80% → 細胞 0.70 ┐
[■■■■■■■■■■ tumor 100%           ]           0.97（換算）     │ (tumor 細胞 3 條 DNA)  │
[■■■■■■■■ tumor 80% |□□ normal 20%]           0.70（換算）     │ (normal 細胞 2 條 DNA) │
[■■■■■■ 60%        |□□□□ 40%      ]          0.48            │ tumor 3.06 份/normal 2 │
[■■■■ 40%          |□□□□□□ 60%    ]          0.29            │ ×100% 樣本 purity 0.97 │
[■■ 20%            |□□□□□□□□ 80%  ]          0.14            │ 來自 ASCAT             │
■ tumor read：HCC1395   ■ normal read：配對的 HCC1395BL       └────────────────────────┘

真實  [混合 read] → [ClairS 找 somatic SNV] → [HP tag 分 HP1/HP2/unphased] → [算 13 項數值] ┐
模擬  [同樣 purity、coverage] → [diplosim] → [HP1/HP2/unphased 計數] → [算同樣的數值]      ┴→ ┆比較兩邊數值┆ 結果下次報告（虛線）
```

- 數字來源：
  - tumor／normal read 比例 100/80/60/40/20%＝subsample t50_n00、t40_n10、t30_n20、t20_n30、t10_n40 的 tumor×／normal×（50/0、40/10、30/20、20/30、10/40）〔R4 §2〕。nominal 是 DNA（read）比例（C-7）。
  - 換算 0.97、0.70、0.48、0.29、0.14〔R4 §2，推論，公式〕：f＝t÷(t＋n)；p＝2f÷(ψ(1−f)＋2f)×0.97，ψ＝3.06。已用公式重算核對：0.8→0.702、0.6→0.480、0.4→0.294、0.2→0.136。
  - ASCAT purity 0.97、ploidy 3.06〔R4〕。
  - tumor HCC1395、normal HCC1395BL〔R4、R6〕。
  - 流程：ClairS PASS ∩ HC → longphase-s haplotag → 每個 SNV 的 HP1／HP2／HP0 ref、alt → `stats()`〔R6 §3、R4 §3〕。模擬端給 purity、coverage（實際也給 SNV 數）〔R4 §3〕。
- 只講設計，不放模擬結果（B-1）。
- 與大綱差異：
  - 頁面不寫 t50…t10 這些 subsample 代號（T-5 內部代號），改用比例條本身辨認；代號只記在這裡。
  - 標題刪掉「tumor read 從 100% 降到 20%」以放進兩行；這個資訊在比例條上。
  - 大綱講稿的「ploidy 換用 2.73 時換算值約高 10%」與「normal 帶少量 tumor DNA 的換算」沒有上頁面，依 S-11 也不進講稿。
  - 加了一張「read 80% → 細胞 0.70」小卡解釋換算（T-5、T-6）。

## p7 t2-stats：13 項 → 6 類

```
圖例：HP1 ▬  HP1 帶 SNV ▬  HP2 ▬  HP2 帶 SNV ▬  unphased ▬  ● alt  ○ ref
┌ unphased read 比例 1項 ┐┌ 各位點 HP 標記比例差異 2項 ┐┌ alt 分在兩條 HP 1項 ┐
│ 5 條 read，1 條灰        ││ 位點A 4/5 有標記｜位點B 2/5 ││ 3 條 alt 在 HP1，1 條在 HP2│
│ 主要 有 HP 標記的比例    ││ 主要 各位點標記比例差異     ││ 主要 鹼基讀錯、HP 標錯     │
│                          ││                             ││ 也受 purity                │
└──────────────────────────┘└─────────────────────────────┘└────────────────────────────┘
┌ minor HP depth<0.1（LOH）3項 ┐┌ depth 變異÷平均 1項 ┐┌ VAF 分位 5項 ┐
│ read 全在 HP1，HP2 只剩虛線框 ││ 12 根 depth 柱＋平均虛線 ││ 0–1 軸上的 SNV＋3 條分位線 │
│ 主要 loss 比例、種類、第二個 CN││ 主要 depth 的額外變異    ││ 主要 purity、CN、clone 比例│
│ 也受 purity（normal 補 minor）││ 也受 CN、purity           ││ 也受 真實端 ClairS 篩選    │
└───────────────────────────────┘└──────────────────────────┘└────────────────────────────┘
```

- 13 項＝`stats()` 輸出 17 項，扣掉 `n_called`、`frac_called`、`depth_median`、`inHP_VAF_q90`〔R7；`lab_report/2026-11-01_diplosim_detection_curve/README.md` 同樣的 13 項〕。
- 6 類的歸法〔推論〕：
  1. unphased read 比例：`HP0_frac_pooled`（1 項）→ `prop_tagged`〔R2〕。
  2. 各位點 HP 標記比例的差異：`tag_frac_SD_sites`、`tag_frac_lt_0.5_sites`（2 項）→ `tag_concentration`〔R2〕。
  3. alt 分在兩條 HP：`split_alt_frac`（1 項；tagged alt ≥ 3 且較多那條 HP 的 alt 占比 < 0.9）→ `base_error`、`mistag_rate`（也可加 `mistag_concentration`）〔R2、R7〕。
  4. LOH：`minorHP_depth_lt_0.1`、`minorHP_depth_q50`、`alt_on_minorHP`（3 項；HP1＋HP2 depth ≥ 10 的位點）→ `prop_pos_lost`、`loss_events`、`prop_pos_second_cna`〔R2〕。`alt_on_minorHP` 也受 `prop_snv_on_b` 影響，歸進這類是為了和 minor HP 放在一起。
  5. depth 變異÷平均：`depth_VMR`（1 項）→ `depth_dispersion`；CN、purity 也改變 depth〔R2、R6 §1〕。
  6. VAF 分位：`VAF_q10`、`VAF_q50`、`VAF_q90`、`VAF_frac_gt_0.6`、`inHP_VAF_q50`（5 項）→ purity、CN、clone 比例；真實端 SNV 先經 ClairS 篩選〔R6 §3〕。
- 所有數值都只算 alt ≥ 3、VAF ≥ 0.08 的 SNV〔R7，`MIN_ALT`、`MIN_VAF`〕；這點沒上頁面。
- 「也受 purity（normal 補上 minor HP）」是推論〔OUTLINE p8 講稿〕。
- 與大綱差異：參數名（`prop_tagged` 等）沒有放上卡片，只寫中文名；放進 JetBrains Mono 會讓每張卡多 1–2 行，6 張卡放不下 824px。參數名已在 p3 出現。
