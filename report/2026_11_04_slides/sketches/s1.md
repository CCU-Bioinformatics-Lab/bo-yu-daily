## p2 t1-machines：兩台機器

誰和誰比：CONIPHER（左，基準）對 diplosim（右，新）。同一列放同一件事（F-5）。CONIPHER 沒有的格子用斜線底。

```
[同一組輸入] clone 數 3 | SNV 數 450 | purity 0.9 | coverage 53× | CN gain／loss | WGD 無      例子：SNV1
┌─ CONIPHER（機器圖示，灰）──────┐   ┌─ diplosim（機器圖示，藍）  新增：read 層級的 phase ─────────────┐
│ [ref▇▇▇▇alt▇▇] ref 36、alt 21   │   │ [同左]  allele A、B copy number 1、1  clone trunk、CCF 1.0  (兩台都有) │
│ allele A、B copy number 1、1    │   ├────────────────────────────────────────────────────────────────┤
│ clone trunk、CCF 1.0            │   │ HP1      ━━●━━ x3 (淺藍, 紅點)   |   ref alt  | 虛線小卡：           │
├/////////////////////////////////┤   │ HP2      ━━○━━ x3 (橘, 白點)     | HP1  0 19  | 真實資料 HP 標號只在 │
│/// 無 read 層級的 phase ////////│   │ unphased ━━○━━ ━━●━━ (灰)        | HP2 27  0  | 一個 phase block 內一致│
│/// ref、alt 不分 HP ////////////│   │                                   | unph 9  2  | diplosim：無 phase block│
├/////////////////////////////////┤   ├────────────────────────────────────────────────────────────────┤
│/// 無 SNV 所在 allele //////////│   │ 真值：SNV 在 allele A（HP1）  ● alt ○ ref  read 條為示意   [實際結果] │
```

結論：兩台都有 ref／alt 與 allele copy number；diplosim 多的是 read 層級的 phase（HP 拆分）與 SNV 所在 allele 真值。

## p4 t1-hpsplit：HP 拆分三方案

```
┌方案 ① 計數後拆分──────┐┌方案 ② ①＋unphased [選擇]┐┌方案 ③ 逐條 read 產生─────┐
│[▇▇▇▇▇▇▇▇▇▇]→ HP1 ▇▇    ││[▇▇▇▇▇▇▇▇▇▇]→ HP1 ▇▇       ││   SNV1    SNV2             │
│ depth、alt   HP2 ▇▇▇   ││ depth、alt   HP2 ▇▇▇      ││ [━━●━━━━━━●━━] 橘框＝共現 │
│                        ││             unphased ▇     ││ ━━○━━  ━━━○━━  ━○━━━━○━  │
│示意                    ││示意                        ││示意                        │
│alt 給 SNV 那條 HP；... ││同 ①，再讓一部分變 unphased ││逐條產生 read；共現＝...    │
│✓ 改動最小              ││✓ 加總仍＝depth、alt        ││✓ 有同 read 共現            │
│✓ HP1＋HP2＝depth、alt  ││✓ 可測 unphased 的影響      ││✓ 最接近真實 long read      │
│✗ 每條 read 都有 HP     ││✗ unphased 比例要另外定     ││✗ 要先定基因組區段的 CN     │
│✗ 沒有同 read 共現      ││✗ 沒有同 read 共現（延後） ││✗ 產生 read 那步整個重寫   │
└────────────────────────┘└────────────────────────────┘└────────────────────────────┘
選 ② 的理由：HP1＋HP2＋unphased＝depth、alt；有 CN 事件也能用；可測 unphased 的影響
```

結論：選 ②；代價是沒有同 read 共現（延後，不是排除）。
