# 生物基因示意圖畫法規則（有日期的增補）

本檔收錄 `report_rule.md`「圖」區塊中，有日期的生物基因畫法規則。它們從 `report_rule.md` 拆出。

- 只在畫到對應關鍵字的概念時讀本檔。關鍵字索引在 `report_rule.md`「圖」第 8 條。
- 本檔和 `report_rule.md` 同等效力。和 `VISUAL_SPEC.md` 衝突時，以本檔為準。
- 固定配色仍在 `report_rule.md`「圖」第 4 條。本檔只引用，不重列。
- 新增生物基因畫法規則時，加進本檔對應小節，附日期，並更新 `report_rule.md` 的索引。

## A. read 上的位點與 SNV 標示

關鍵字：read、alt、ref、SNV 名稱、位點圖例

1. read 上的位點圖例：實心紅點標「alt」，空心白點標「ref」。不要寫「有突變／沒有」。（2026-10-20）
2. 同一頁有多個 SNV 時，每個 SNV 直接標名稱（SNV1、SNV2…）。後面步驟的樹也標同一個名稱。（2026-10-20）

## B. IGV 風格 read 堆疊圖

關鍵字：IGV、read 堆疊、read 層資料、HP 分區

1. 構圖：上方放參考序列與位點標示。下方灰色 read 一條條往下疊。位點上紅格＝alt，白格＝ref。依組合分群。（2026-10-20）
2. 依 HP1、HP2 分區。設計樹上的每個 SNV 都要出現在圖上，並放在它所屬的 HP 區。（2026-10-20）
3. 不標各組 read 數，只畫 read 堆疊本身。（2026-10-20；取代早先「標 read 數」的寫法）

## C. 演化樹（設計樹、軟體輸出樹）

關鍵字：演化樹、clone tree、設計樹、真值樹、軟體輸出樹、CCF 標示

1. 設計（真值）樹依 HP1、HP2 分成兩棵並排。在邊上標每個 SNV 落在哪條 haplotype、哪個 clone。（2026-10-20）
2. 設計樹的 SNV 名稱與先後關係，要和 IGV 圖一致（見 B）。（2026-10-20）
3. 軟體輸出的樹用和設計樹相同的格式：同樣分 HP1、HP2 兩棵，標同樣的 SNV。這樣才能直接比對。（2026-10-20）
4. 節點標 CCF（例如 100%、40%、30%）。文字顏色和該 clone 節點相同。根 clone 用黑色。（2026-10-20）

## D. 困難情境的機制圖

關鍵字：subclonal CN、copy number、低 purity、低深度、CCF 推不準、陷阱、限制

這些是 `report_rule.md`「圖」第 7 條（困難情境要畫機制圖）的細則。

1. subclonal CN 這類「細胞之間不同」的問題：並排畫 main clone 與 subclone 兩群細胞，各自標 CN（例如 CN 2 → CN 3）。（2026-10-20）
2. 「某個量太低」造成的問題（低 purity、低深度）：每個量畫成數值偏低的量表。各自用箭頭接到它造成的中間效應。最後匯合指向受影響的結果（例如 CCF）。（2026-10-20）
3. 使用者不要推導數值（例如 CCF）時，結果只用 ✓／✗ 加短語。（2026-10-20）
