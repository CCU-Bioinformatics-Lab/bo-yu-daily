## 逐頁大綱

### 0 封面與主問題
- **P1 封面**：「只用 bulk 分不出的樹關係，long read 能幫忙嗎？」
- **P2 主問題**：一個主問題，下面三個子問題（哪裡錯／怎麼補／怎麼證明），各標對應段落。P10 逐一回答。

### 1 現象
- **P3 標題**：「HCC1395 的樹跟著事先分的群改變，我們分不出哪棵對」
  - 圖上排（概念小圖）：正常細胞 → 祖先 clone → 子 clone（＝腫瘤演化樹）；旁邊兩棵小樹圖示「線性」「分支」。中排：bulk 定序把很多細胞混在一起；短讀（很多短條）vs 長讀（幾條長條，跨過多個突變位置）。
  - 主圖：30,368 個突變 → 事先分群（依「帶突變 read 的比例」分堆）→ PhyClone 排樹。分 5 群 → 線性樹；合併成 3 群 → 抽樣的樹中線性約一半、分支約一半。
  - 頁面文字（≤2 句）：群的分法改了，樹就改了。沒有標準答案時，分不出哪棵對。
  - 講稿：只有一個樣本。腫瘤細胞比例用文獻值 0.99；我們的工具估 0.992，也只是估計值，都不是真值。3 群是我們手動合併相近的群。3 群時兩個子群的比例是 0.65 與 0.26，加起來 0.91，不超過上層的 0.98，所以排成兄弟或排成一串都合格，下一段會說明這就是第一個陷阱。留下問題：為什麼樹會不穩？

### 2 原因
- **P4 標題**：「PhyClone 只吃每個突變的 read 數和拷貝數」
  - 圖：四格流程：腫瘤組織（clone＋灰色正常細胞，標 purity）→ reads 疊在突變位置，數有／沒突變 read，算 VAF → PhyClone 輸入列白話（沒突變 read 數、有突變 read 數、腫瘤拷貝數兩份各幾份、正常拷貝數、purity、事先分的群）→ 演化樹。
  - 頁面文字（≤2 句）：每一列是一個突變在一個樣本的資料。輸出是樹，以及每個突變掛在哪個節點。
  - 講稿：purity 與拷貝數是固定輸入，不在模型裡估。每個突變每個樣本只吃一組拷貝數，等於假設所有腫瘤細胞拷貝數相同（論文描述，作者列為主要限制）。群只能合併不能拆。
- **P5 標題**：「bulk 有兩個分不出來的地方：兄弟 clone 與 multiplicity」
  - 左（陷阱 1，標「P3 的情況」）：真樹 A→B、A→C，B、C 的 CCF 相近（首次定義 CCF）。旁註比例規則：B＋C 不超過 A，所以兄弟和一串都合格。數線上兩點重疊。錯誤結果：併成一群，或排成 A→B→C。
  - 右（陷阱 2）：purity＝1。60% 腫瘤細胞 1:1，40% 腫瘤細胞 2:1（第一份多一份）。兩種突變的 VAF 都是 0.333：解釋一，突變在第二份（沒增加），在一份拷貝上，CCF＝0.8；解釋二，突變在第一份、早於增加，只在那 40% 細胞裡，在兩份拷貝上，CCF＝0.4。兩種 CCF 旁標「樹上位置也不同」。標「multiplicity＝突變位在幾份拷貝上」。
  - 頁面文字（≤2 句）：比例相近的兄弟 clone 會被併錯或排錯。同一個 VAF 會因 multiplicity 不同，對應到兩種 CCF。
  - 講稿：1:1、2:1 是兩份同源染色體各幾份。平均每個細胞 2.4 份拷貝；解釋一 0.8÷2.4，解釋二 0.4×2÷2.4，都是 0.333。前提：已知 40% 細胞多一份，且多的是第一份。PhyClone 每個突變只吃一組拷貝數，連這種一部分細胞改變的情況都表達不了（如第 4 頁所說）。留下問題：有人用 long read 補過嗎？

### 3 空缺
- **P6 標題**：「我們找到的 22 篇中，只有 1 篇用長讀加單細胞驗證，而且只在事後挑樹」
  - 圖左：2×2 篇數表（短讀無 6、長讀無 4、短讀有 11、長讀有 1），長讀有那格橘框。首次定義單細胞真值樹。
  - 圖右：肺癌論文兩棵候選樹（分支 vs 線性，CCF 0.616 與 0.212，兩棵都符合比例規則），同一條 read 帶兩個突變 → 選線性。標「事後挑樹，不在建樹模型內」。
  - 頁面文字（≤2 句）：只有 1 篇同時有長讀與單細胞資料。它用長讀事後挑樹，沒有放進建樹模型。
  - 講稿：分類是我們自己分的（分析推論）。肺癌論文選樹的病人和做單細胞驗證的病人不同，單細胞只做局部佐證，沒有完整真值樹。ONT 是做長讀定序的公司；另有一篇 2026 會議摘要用同一批 ONT 細胞株，只有摘要。短讀方面，已有方法把同一條 read 上的兩個突變放進模型，但 read 太短；例如其中一個方法只用拷貝數正常的區域。所以空缺是：長讀證據還沒進入建樹模型。留下問題：我們要怎麼補？

### 4 解法
- **P7 標題**：「HP 計數看出改變的是哪一份同源染色體 → 幫助陷阱 2」
  - 圖：兩份同源染色體、異型合子 SNP、HP1／HP1-1／HP2／HP2-1／unphased 五種 read（固定配色）、兩段 phase block，中間缺口。右下：回到 P5 的陷阱 2，多一份的是 HP1。帶突變 read 都在 HP2 → 解釋一，CCF＝0.8；都在 HP1 → 解釋二，CCF＝0.4。
  - 頁面文字（≤3 句）：HP 是染色體標籤，不是 clone 標籤。腫瘤突變只在其中一份。每個突變的 read 數再拆成 HP1、HP2、分不出來三類。
  - 講稿：HP1／HP2 只在同一段 phase block 內有意義，不代表父或母，跨 block 不能接，block 內也可能偶爾接錯。HP 計數能確定突變在哪一份：在沒增加的那份，multiplicity 一定是 1；在增加的那份，有時還要配合細胞比例或發生先後才分得出（推論）。只剩一份同源染色體的區段沒有異型合子 SNP，分不出兩份；HCC1395 腫瘤細胞比例約 0.99，正常細胞的 read 太少，救不回來。
- **P8 標題**：「同一條 read 上兩個突變的組合，能排除不可能的關係 → 幫助陷阱 1」
  - 圖：四欄（同一 clone／a 是 b 的祖先／b 是 a 的祖先／分支），每欄一棵小樹，下面三種 read 組合畫「有／無」。分支欄連回陷阱 1。
  - 頁面文字（≤2 句）：每種關係都有不會出現的組合。看到哪些組合，就排除哪些關係。
  - 講稿：家族比喻：祖先的突變傳給所有後代；分家兄弟各自的新突變，不會出現在同一個人身上。只看到「兩個都有」時，分不出同一 clone 還是祖先關係。前提：同一份同源染色體、同一段 phase block、該份只有一個拷貝、中間沒有拷貝數斷點、突變沒丟失。定序錯誤會造出假的「只有 a」；突變平均約每十萬個鹼基才一個，蓋到兩個突變的 read 可能不多。所以用軟性分數不硬判。設計是把 HP 計數和共現放進 PhyClone 的樹分數（設計提案，尚未實作）；提示該拆的群要在分群階段處理（推論）。留下問題：怎麼證明有幫助？

### 5 驗證
- **P9 標題**：「沒有資料同時有長讀和真值樹，所以先用模擬資料驗證」
  - 圖左：2×2 象限（長讀有無 × 真值樹有無）：PhyClone 論文資料與 SMC-Het 51 個模擬腫瘤（有真值、無長讀）；6 株 ONT 細胞株（有長讀、無真值）；Liu 2026 小鼠子株（虛線，參考樹非真值）。兩條路線：①模擬資料加模擬長讀證據 → 檢查樹有沒有變準；②真實細胞株 → 只檢查可用量與相容性。
  - 圖右（小）：祖先關係分數示意：真樹分支、預測線性，標出被判錯的配對。
  - 頁面文字（≤2 句）：先在有真值的模擬資料上驗證。評分逐對檢查祖先關係，並單獨看分支配對。
  - 講稿：SMC-Het 是公開建樹競賽。細胞株稀釋標籤是設計比例，不是實測 purity。小鼠子株的樹是用同一批長讀突變建的，拿來評分會循環，所以不算真值。模擬長讀的程式與建樹模型分開寫，並加入違反假設的情境，避免自己出題自己答。競賽的樹分數也由祖先關係算出，但把所有配對合成一個數字；我們推論分支錯誤會被大量正確配對稀釋，所以另外看分支配對。真實資料方面，HCC1395 拷貝數改變區已有約 2 萬對同一條 read 上的兩個突變的初步計數，但還沒依 HP 篩選，多在拷貝數多於一份的區段。留下問題：證明之前，資料夠不夠用？

### 6 總結
- **P10**：三個子問題各一句回答（只用前面講過的詞）：
  - ①哪裡錯：兄弟 clone 與 multiplicity，只用一個 bulk 樣本分不出來。
  - ②怎麼補：HP 計數幫 multiplicity；同一條 read 上兩個突變排除不可能的關係（設計提案）。
  - ③怎麼證明：尚未證明，這是驗證計畫：先在模擬資料上驗證。
  - 風險（回扣 P8、P9）：「該份只有一個拷貝的區段」可用的數量還沒算，可能不多。
  - 下一步：①在 HCC1395 算「該份只有一個拷貝的區段」、依 HP 篩選後的可用數量；②用這些數量設定模擬資料，在有真值的模擬資料上驗證。
