### 1 Long read 方法論文和 single-cell 演化樹答案調查
- **P3 標題**：「沒有論文用 long read 建完整的樹，再用單細胞樹檢查」
  - 圖左（概念小圖）：上排：正常細胞 → 祖先 clone → 兩個子 clone 的小樹（＝腫瘤演化樹）。中排：短讀（很多短條）vs 長讀（幾條長條，跨過多個位置）。下排：一顆顆細胞 → 細胞樹，雙箭頭「對照」bulk 推出的樹。
  - 圖右：2×2 矩陣。橫軸「建樹用的 read：短讀／長讀」，縱軸「有無單細胞真值樹：無／有」。四格大數字：短讀無 6、長讀無 4、短讀有 11、長讀有 1。長讀有那格用橘框，標「我們想做的位置」。下方小字「共 22 篇」。
  - 頁面文字（≤2 句）：長讀加單細胞真值的只有 1 篇；它只驗證了部分病人。
  - 講稿：分類是我們依「建樹 read 種類」與「有無單細胞樹」自己分的（分析推論）。那 1 篇是 2022 年的肺癌論文，單細胞驗證的病人和 long read 選樹的病人不同，下一頁講它。另有一篇 2026 年會議摘要用同一批 ONT 細胞株，只有摘要，是最接近的競爭者。
- **P4 標題**：「肺癌論文用同一條 read 上的兩個突變，選出線性樹」
  - 圖：兩棵候選樹，都從主幹 C-1（CCF 1）出發。分支樹：C-1→C-2、C-1→C-3。線性樹：C-1→C-2→C-3。C-2 標 CCF 0.616、C-3 標 CCF 0.212。旁邊畫比例規則：0.616＋0.212＝0.828 ≤ 1，兩棵都合格。下方一段 DNA（畫成同一條 haplotype），兩個突變位置，幾條 long read，其中有 read 同時帶兩個紅點。分支樹標「排除」，線性樹標「保留」。
  - 頁面文字（≤3 句）：CCF＝帶這個突變的腫瘤細胞比例。兩棵樹都符合比例規則。分支樹的兩個突變在不同細胞裡，同一條 read 不會同時帶兩個。
  - 講稿：前提是兩個突變在同一份同源染色體上，第 10 頁會講完整條件。C-2、C-3 是突變群，read 證據只針對特定一對突變。作者只拿它事後挑樹，沒有放進建樹模型。

### 2 目前模擬和真實資料狀況
- **P5 標題**：「模擬資料有真值樹沒有 long read，真實資料相反」
  - 圖：2×2 象限，橫軸「long read：無／有」，縱軸「真值樹：無／有」。
    - 有真值、無 long read：PhyClone 論文資料（7 組模擬＋1 組真實卵巢癌，短讀）、SMC-Het 競賽 51 個模擬腫瘤（已下載）。
    - 無真值、有 long read：6 株 ONT 腫瘤細胞株（HCC1395 等）。
    - 有 long read、有參考樹（非單細胞真值）：Liu 2026 小鼠腫瘤 23 個子株，樹由 bulk 推論，未下載。用虛線橘框，與真值格分開。
    - 兩條驗證路線用箭頭疊在象限上：①模擬資料 → 「加上模擬的 long read 證據」→ 檢查樹有沒有變準；②真實細胞株 → 「只檢查資料能不能用、和候選樹是否相容」。
  - 頁面文字（≤2 句）：沒有一份資料同時有 long read 和單細胞真值。所以先在模擬資料上加 long read 證據來驗證。
  - 講稿：PhyClone 是本研究要改良的建樹程式；SMC-Het 是公開建樹競賽。purity＝樣本中腫瘤細胞的比例。細胞株的稀釋標籤是設計比例，不是實測 purity。真實細胞株不宣稱準確率。模擬 long read 證據的程式與建樹模型分開寫，並加入違反假設的情境（染色體來源標錯、拷貝數估錯、read 太少），避免「自己出題自己答」。
- **P6 標題**：「HCC1395 只跑 PhyClone，樹的形狀跟著事先分的群走」
  - 圖：左格「30,368 個突變」→「事先分群」（點依「帶突變 read 的比例」分堆；這個比例在第 7 頁叫 VAF）→「PhyClone 排樹」。右兩列：分 5 群 → 一棵線性樹；合併成 3 群 → 抽樣的樹中線性約一半、分支約一半。
  - 頁面文字（≤2 句）：群的分法改了，樹就改了。沒有標準答案時，我們分不出哪棵對。
  - 講稿：這次只有一個 sample。purity 用文獻值 0.99，不是 nominal，也不是實測。PhyClone 只能合併事先分的群，不能拆開，所以樹受分群限制。需要 long read 的額外證據。

### 3 重新釐清重建演化樹的輸入和輸出
- **P7 標題**：「PhyClone 吃每個突變的 read 數和拷貝數，吐出演化樹」
  - 圖：四格流程：①腫瘤組織（clone 細胞＋灰色正常細胞，標 purity）→ ②reads 疊在突變位置，數「沒突變 read 數」「有突變 read 數」，算 VAF → ③PhyClone 方塊，輸入列白話：沒突變 read 數、有突變 read 數、腫瘤拷貝數（兩條各幾份）、正常拷貝數、purity、事先分的群（可不給）→ ④演化樹（突變掛到節點，節點大小＝細胞比例）。
  - 頁面文字（≤2 句）：每一列是一個突變在一個樣本的資料。輸出是樹，以及每個突變掛在哪個節點。
  - 講稿：purity 與拷貝數是固定輸入，不在模型裡估；purity 不給時預設 1。每個突變每個樣本只吃一組拷貝數，只能表達所有腫瘤細胞相同的拷貝數。群只能合併不能拆。multiplicity 在計算中被加總掉，不輸出。不讀正常樣本的 reads。
- **P8 標題**：「從 VAF 到演化樹，有兩個陷阱」
  - 左（陷阱 1：比例相近不代表同一個 clone）：真樹 A→B、A→C，B、C 的 CCF 都約 0.4；一條 0–1 數線上兩點重疊；錯誤結果：B、C 併成一群，或排成 A→B→C。
  - 右（陷阱 2：部分細胞拷貝數改變）：60% 腫瘤細胞 1:1、40% 腫瘤細胞 2:1（某一份多一個）。突變在被複製的那份（複製後兩份都帶突變）→ VAF 0.583；在沒被複製的那份 → VAF 0.417。圖上寫前提：purity＝1、突變在所有腫瘤細胞（CCF＝1）、突變早於複製。標「multiplicity＝突變位在幾份拷貝上」。
  - 頁面文字（≤2 句）：比例相近的兄弟 clone 會被併錯或排錯。同一個 CCF 會因拷貝數給出兩種 VAF。
  - 講稿：解釋 1:1、2:1 是兩份同源染色體各幾份。0.583 怎麼算：(0.6×1＋0.4×2)÷(0.6×2＋0.4×3)。PhyClone 每個突變只吃一組拷貝數，所以兩者都換不到正確 CCF。預告：第 9 頁幫助陷阱 2，第 10 頁幫助陷阱 1。

### 4 其他論文沒有的 long read 特徵
- **P9 標題**：「long read 能分辨 read 來自哪一份同源染色體」
  - 圖：上下兩份同源染色體，幾個異型合子 SNP（兩份顏色不同）；HP1（#2C5F9E）、HP1-1（#8FB3E0，帶紅點突變）、HP2（#D9772B）、HP2-1（#F2B880，帶紅點）、unphased（灰）五種 read，每種有圖例與一句白話；兩段 phase block 括號，中間缺口。右下小圖：陷阱 2 的 40% 細胞，看得出多一份的是 HP1 還是 HP2。標「幫助陷阱 2」。
  - 頁面文字（≤3 句）：HP 是染色體標籤，不是 clone 標籤。腫瘤突變只在其中一份。每個突變的 read 數再拆成 HP1、HP2、分不出來三類（HP 計數）。
  - 講稿：HP1／HP2 只在同一段 phase block 內有意義，不代表父或母，跨 block 不能接。HP 計數能看出改變的是哪一份；帶這個改變的細胞比例仍要另外估（推論）。longphase-s 還有其他少數標記，圖上省略。HCC1395 有些區段只剩一份同源染色體，那裡分不出兩份。
- **P10 標題**：「同一條 read 上兩個突變的組合，指出誰是誰的祖先」
  - 圖：四欄（同一 clone／a 是 b 的祖先／b 是 a 的祖先／分支），每欄一棵小樹，下面三種 read（兩個都有、只有 a、只有 b）畫「有」或「無」。所有 read 畫在同一份同源染色體上。分支欄連回陷阱 1，標「幫助陷阱 1」。
  - 頁面文字（≤2 句）：每種關係都有不會出現的組合。看到哪些組合，就能排除哪些關係。（同一 clone：不會只有 a、不會只有 b；a 是 b 的祖先：不會只有 b；b 是 a 的祖先：不會只有 a；分支：不會兩個都有。）
  - 講稿：用家族比喻：祖先的突變會傳給所有後代；兩個分家的兄弟各自的新突變，不會出現在同一個人身上。前提：兩個突變在同一份同源染色體、同一段 phase block，該份只有一個拷貝，中間沒有拷貝數斷點，突變沒有丟失，read 要同時蓋到兩處。沒看到「兩個都有」可能只是 read 太少，所以用軟性分數不硬判。我們的設計是把 HP 計數和這類 read 證據放進 PhyClone 的樹分數（設計提案，尚未實作）。第 4 頁肺癌論文只用它事後挑樹。

### 5 用 benchmark 拆解重建演化樹問題
- **P11 標題**：「SMC-Het 把建樹拆成五個子任務，long read 能幫後三個」
  - 圖：五站管線：purity → clone 數 → 每個 clone 的細胞比例 → 突變分群 → 樹。後三站藍色，下面各一個小圖示：HP 計數（兩色 read）、同一條 read 上兩個突變。標「推論」。
  - 頁面文字（≤2 句）：五站對應建樹的五個問題。後三站正是第 8 頁兩個陷阱發生的地方。
  - 講稿：SMC-Het 原本有七個子題，分三組；五站是我們依任務順序重排的。HP 計數也可能幫到前兩站的拷貝數估計。PhyClone 沒有參加這個競賽。
- **P12 標題**：「部分細胞的拷貝數變化是重要誤差來源，評分要看祖先關係」
  - 左：48 個「部分細胞拷貝數增加」的區段，拷貝數工具漏掉 25 個（紅點 25、灰點 23）。
  - 右：真樹分支、預測成線性，競賽的樹分數仍有 0.875（滿分 1）；祖先關係分數（逐對檢查誰是誰的祖先，數對了幾對）會明確扣分。
  - 頁面文字（≤2 句）：拷貝數工具漏掉一半的部分細胞增加。樹畫錯了，樹分數仍然很高。
  - 講稿：論文的主結論是方法選擇影響最大，部分細胞拷貝數是重要誤差來源之一。0.875 是我們用 10 個突變、3 個節點的小例子手算的，不是論文結果，把所有突變放成一群的答案也有約 0.54。所以我們主要用「祖先關係對不對」來評分。
