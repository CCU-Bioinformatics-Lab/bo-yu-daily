4 · Long read 特徵

HP 是 germline homolog 標籤，不是 clone 標籤

示意：同一 PS block 內的四種 read

HP1

爸爸那條，正常

HP1-1

爸爸那條，帶 somatic SNV

HP2

媽媽那條，正常

HP2-1

媽媽那條，帶 somatic SNV

紅色標記＝somatic SNV。HP 只說 read 來自哪條 homolog。

範圍：HP1／HP2 只在同一 sample、chromosome、PS 內有意義。

read 層級：HP:1-1 的 read 在待測 SNV 位點仍可能是 REF。

unphased：HP3、無 tag、PS 不符的 read 歸入 unphased。不推定 allele 或 clone。
