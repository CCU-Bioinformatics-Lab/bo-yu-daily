總結

五個問題的答案

1

文獻調查

只有一篇肺癌論文用長讀加單細胞樹；它只驗證部分病人，也只拿 read 事後挑樹。

2

資料狀況

模擬資料有標準答案，細胞株有 long read；先在模擬資料加 long read 證據來驗證。

3

輸入與輸出

PhyClone 吃 read 數、拷貝數與 purity；比例相近和部分細胞拷貝數改變會讓樹出錯。

4

Long read 特徵

HP 計數幫助陷阱 2；同一條 read 上的兩個突變幫助陷阱 1。

5

Benchmark 拆解

建樹拆成五個子任務；手算例子裡畫錯的樹仍有 0.875，所以改看祖先關係分數。

下一步

先在 HCC1395 量化 HP 計數與同一條 read 上兩個突變的數量（第 5 頁路線②），再用這些數量設定模擬資料來驗證（路線①）。

最後回到開頭的五個問題。第一，只有一篇肺癌論文同時用長讀和單細胞樹，只驗證部分病人，也只拿 read 事後挑樹。第二，模擬資料有標準答案，細胞株有 long read，沒有一份兩者都有，所以先在模擬資料加上 long read 證據來驗證。第三，PhyClone 吃 read 數、拷貝數和 purity；比例相近的兄弟 clone 和部分細胞拷貝數改變，會讓樹出錯。第四，HP 計數和同一條 read 上的兩個突變，分別幫助這兩個陷阱。第五，我們手算的小例子裡，畫錯的樹分數仍有 0.875，所以改看祖先關係分數。下一步有兩件事。第一，在 HCC1395 上量化這兩種證據各有多少。第二，用這些數量設定模擬資料，在有標準答案的資料上驗證樹有沒有變準。
