結論是：long read 能分辨 read 來自哪一份同源染色體。同源染色體是每條染色體的兩份，一份來自父方，一份來自母方。大家看圖，兩份在一些位置天生不同，叫 germline 異型合子 SNP。read 跨過這些位置，就能分到 HP1 或 HP2。HP1、HP2 只是標號，不代表父或母。它只在同一段 phase block 內有意義，缺口兩邊不能接。沒蓋到這些位置的 read 分不出來，畫成灰色。HP 也不是 clone 標籤。腫瘤突變只在其中一份，所以帶突變的 read 是 HP1-1 或 HP2-1。右下角回到陷阱 2：HP 計數看得出多一份的是哪一份。帶這個改變的細胞比例還要另外估，這是推論。分 read 的程式還有少數其他標記，圖上省略。HCC1395 有些區段只剩一份同源染色體，那裡分不出兩份。
