## 判準（寫進 BRIEF）

single-cell 樹分四級（對應 TSV `sc_truth_strength`）：

| 級 | 意思 | 篇 |
|---|---|---|
| 驗證用真值 | 用 single-cell 樹當答案，評分 bulk 建樹方法。PhyClone 的標準 | M01、M06 |
| 局部佐證 | single-cell 只支持部分突變或部分 clone | B04、B05、H01 |
| 只有參考樹 | 作者用 single-cell 資料自建樹，沒有拿來評分別的方法 | A01–A05、B03、R01 |
| 無 | 沒有 single-cell 樹 | 其他 9 篇 |

P4 的格子只寫「有」「無」。「局部」「只在程式碼」「只做驗證」一律算「無」，細節放講稿。

其他判準：
- 長讀或 HP 只用來驗證時，不算有該特徵；P3 的平台列算短讀。
- 「同 read 共現」＝同一條 read 上有兩個體細胞變異（SNV 或 SV 斷點）。
- 「BAM 可下載」＝比對檔或原始 read 公開可下載（`report_rule.md` 文字與表格第 3 條）。受控、需簽資料協議、只公開計數，都算「無」。

## 第二大段：各論文的模擬資料與真實資料怎麼產生？

### P5 標題：「7 篇有模擬，只有 1 篇產生 read，0 篇產生長讀」
- 圖：三層生成路線，由左到右越接近真實定序。
  - 事件層：設計樹 → 拷貝數 profile，沒有 read 數。代表：拷貝數建樹方法（B05）。
  - 計數層：設計樹 → 每個 clone 的比例 → 抽 read 數。代表：PhyClone 的四種模擬器（M01）；配對 read 方法（M02，抽同 read 配對計數）；SV 聯合方法（M05）；單細胞輔助方法（M06，bulk＋單細胞 RNA 計數）；單細胞 DNA 聯合方法（M04）。
  - read 層：真實 read 依 haplotype 切開 → 植入突變 → 腫瘤 BAM。代表：建樹競賽（M07）。
- 頁面文字（≤2 句）：計數層沒有 read 序列，所以沒有 HP 標籤與 phase block。只有建樹競賽產生 read，而且是短讀。
- 講稿：有些計數層模擬已帶 haplotype 或同 read 資訊，但只是給模型的數字，不是 read。PhyClone 的模擬多數 purity＝1、拷貝數簡單。配對 read 方法的資料由自己的模型生成，對自己有利。

### P6 標題：「建樹競賽先把 read 依 haplotype 分開，再植入突變」
- 圖：六步流程。
  1. 正常人 HG002 的 300× 短讀（白話：公開的標準正常人樣本）。
  2. 定相：把 read 分到兩份同源染色體（phased 區段中位長約 85 kb）。
  3. 依「haplotype × 染色體」切成 read 池。
  4. 依 clone 比例與拷貝數調深度。
  5. 植入 SNV 與 SV（子 clone 帶父 clone 的突變）。
  6. 合併成腫瘤 BAM，再呼叫變異。
- 頁面文字（≤2 句）：每個突變被植入特定 haplotype 的 read 池。參賽者只拿到變異清單，看不到 read。
- 講稿：
  - 這是我們的推論：真值檔可能保留每個突變的 haplotype，但我們還沒核對。正常 BAM 加植入突變的 BAM 有公開版本。
  - 這也是推論：照這個流程改用長讀，就能產生長讀版驗證資料。
  - 最大難點：短讀版每個突變各自挑 read。長讀版要先把整條 read 指派給一個 clone，再放上這個 clone 的全部突變，同 read 共現的答案才對。
  - 其他難點：haplotype 切分要用父母資料，不能用我們要測的 phasing 工具；底層深度要夠，不能複製 read；植入工具對長讀的支援不明；參考基因組要轉成 GRCh38。
  - 橋接：「模擬的答案是設計出來的。真實資料的答案從哪來？」

### P7 標題：「真實資料的 single-cell 樹多半是參考樹，只有 2 棵被拿來評分建樹」
- 圖：兩組 single-cell 技術。每格標：癌別、細胞數、樹種類（SNV 樹／拷貝數樹）、是否被拿來評分 bulk 建樹（✓／✗）。
  - 標靶 panel（只看選定基因）：
    - 卵巢癌單細胞研究（R01）：1,529 nuclei，3 位病人，SNV 樹，✓（被 PhyClone 拿來評分）。
    - 胰臟癌（A03）：16 位病人；只有 1 位建樹（8,061 nuclei），SNV＋刪除樹，✗。
    - 混合型白血病（A05）：58,807 cells，14 位病人，SNV 樹（20 基因），✗。
  - 淺層全基因體：
    - 卵巢癌 cfDNA 追蹤（A01）：21,916 cells，24 位病人，拷貝數樹，✗。
    - 肺癌增殖研究（A02）：14,994 cells，1 位病人，SNV 樹，✗。
    - 單細胞突變過程研究（B03）：22,057 cells，23 cases，拷貝數樹，✗。
    - 卵巢癌細胞株（M06）：取用前人的淺層全基因體 clone 樹（拷貝數＋斷點＋SNV）；評分用 360 顆單細胞 RNA，✓。
    - 白血病 Strand-seq（A04）：8 位病人，542 cells，SV＋haplotype 拷貝數樹，✗。
- 頁面文字（≤2 句）：single-cell 樹多半是作者自建的參考樹。被拿來評分 bulk 建樹的只有 2 棵，而且都是短讀。
- 講稿：這 2 棵樹對應 P3 的 2 篇：PhyClone 用卵巢癌單細胞研究的樹；細胞株研究用前人的 clone 樹。細胞株研究的 bulk 輸入是單細胞資料合併而成，不是另一批定序。拷貝數樹和 SNV 樹不完全相同。只有局部佐證的 3 篇沒有完整 single-cell 樹，所以不列。

### P8 標題：「真實長讀資料都沒有驗證用真值樹」
- 圖：長讀真實資料表（樣本／平台／樹的來源／BAM 可下載）。長讀進入分析的列在上；只做驗證的列在最下一行。
  - 肺癌病人 20 位（B04）：ONT＋Illumina；2 位病人有單細胞拷貝數；BAM 可下載 無。
  - 只做驗證：單細胞突變過程研究（ONT）、HCC1395 社群資料（PacBio）；BAM 可下載 無。
- 頁面文字（≤2 句）：長讀資料都沒有驗證用真值樹。可下載的 ONT 只有肺癌細胞株。
- 講稿：病人長讀資料都要申請才能取得。

### P9 總結
- 存在嗎：不存在。最接近的那篇只有局部單細胞佐證，長讀只用來事後挑樹。
- 前人怎麼做：7 篇有模擬，只有 1 篇產生 read，0 篇產生長讀。真實資料的驗證用真值只有 2 篇，都是短讀。
- 對我們的參考（分析推論）：照建樹競賽流程，改用長讀產生 read 層級模擬，驗證樹形。
