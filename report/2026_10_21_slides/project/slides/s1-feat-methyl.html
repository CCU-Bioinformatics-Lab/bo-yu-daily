這頁的結論是：只用 PCDH 這段區域的甲基化，排出的樹分群和 single-cell 真值樹很像。PCDH 是第 5 號染色體上一群原鈣黏蛋白基因，這裡的甲基化會隨機改變，適合當條碼。最左邊，細胞分裂時條碼照抄給 subclone，偶爾一格改變。第二張卡，先依 HP 把 read 分開，因為兩條同源染色體的條碼本來就不同。第三張卡是建樹的核心：把同一 HP 的 read 排成矩陣，每列一條 read、每欄一個 CpG。缺的格子，用條碼最像的三條 read 投票補上。兩條 read 差幾格就是距離，再用 UPGMA 這種平均距離分群法，先合併最像的 read，一路合成一棵樹。最右邊，左半是作者用一段 PCDHα 區、HP1 的 read 排出的樹，色條代表每群有多少 read。右半是同一位病人的真值樹：每顆細胞先長成 colony 再定序。DNMT3A 的 clone 占 84%，裡面分出 JAK2 65% 和 CBL 12%，非癌細胞 16%。同色是同一群，大小接近。不過作者只用目視比對，分支長度也對不上，而且這是 read 的樹，不是突變的 clone 樹。接下來看我們怎麼驗證新軟體。
