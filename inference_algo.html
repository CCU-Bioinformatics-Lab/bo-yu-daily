推理演算法怎麼找出候選樹？

把模型想成評分規則，把推理演算法想成搜尋隊：搜尋隊提出許多候選樹，模型逐一評分，最後留下最能解釋 bulk 定序資料的一群答案。

目前正式實作仍是 compound MCMC；新 SMC 只有設計規格，尚未實作或升級為 active

先分清楚：現在使用的 vs. 下一個候選

兩者讀取同樣的模型資料、評估同一個「看過資料後的可能答案分布」（posterior）；差別只在「如何搜尋答案」。

CURRENT · 已實作

Compound MCMC

依序更新 SNV 歸屬、clone 比例與樹的分支。它仍是目前 active backend，也是新方法要比較的基準。

Rao–Blackwellized annealed SMC

讓一群可平行運作的候選答案（particles）從簡單起點逐步靠近完整 posterior，專門面對多種可能樹形。

不可混用：目前不能把 SMC 描述成已完成的新推理結果；在程式、測試與 promotion gates 全部通過前，它只是一份候選演算法藍圖。

為什麼選 SMC 當下一個候選？

不是因為 SMC 永遠最好，而是它比較貼合目前模型同時具有「離散樹形」與「連續比例」的特性。

混合兩種答案

樹怎麼連是離散選擇；clone 占比是連續數值。單靠只擅長連續參數的方法不夠。

答案可能分成多群

好幾種樹都可能合理，而且彼此距離很遠。一群 particles 比單一路徑更有機會保留多種候選。

天然適合平行

多個候選答案可以分工評估，較符合目前 C++ backend 想利用平行運算的方向。

候選 SMC：六步走到完整 posterior

像從容易的練習題慢慢加難度。β 表示目前用了多少真實資料的評分力量：從 0 開始，走到 1 才是完整 posterior。

只要 β 還沒到 1，就重複「加難度 → 加權 → 重新取樣 → 再探索」

Rao–Blackwellization：不必替每個 SNV 擲骰子

這個名字很長，做法其實像「把所有合理放法都評分，再依分數分配支持度」。

每個 SNV 都有多種合理放法

它可能屬於不同 clone，也可能有不同 multiplicity。copy number 先限制哪些候選是合法的。

全部評分，不只抽中一個

模型比較每個「clone × multiplicity」組合能多好地解釋 reads，再把所有候選加總成該 particle 的分數。

最後仍然能輸出歸屬機率

把保留下來的 particles 再加權平均，就得到 SNV→clone posterior 與 multiplicity posterior。

固定的模型介面不變

換推理演算法，不等於換資料或換生物模型。SMC 若實作，仍必須遵守同一份 input/output contract。

固定輸入

  • 每個 eligible SNV 的 REF／ALT reads
  • ASCAT major／minor／total CN
  • 固定 ASCAT purity = 0.99
  • 模型設定：例如固定候選 clone 容量 K
→

固定研究輸出

  • 候選 tumor evolutionary tree
  • clone CCF 與可信範圍
  • SNV→clone assignment posterior
  • multiplicity posterior 與分支支持度

什麼時候 SMC 才能升為 active？

不是程式能跑就算完成。它要先證明算得對、跑得穩、能續跑，而且至少不比目前基準差。

1 · 數值對得上

C++ 與小型 PyMC reference 的分數、歸屬支持度與 posterior 摘要一致。

2 · 模擬資料找得回來

已知答案的 synthetic data 能恢復樹形、CCF、SNV 歸屬與 multiplicity。

3 · 重跑結果穩定

多次獨立 pilot 對 assignment、CCF 與 edge support 給出相近答案。

4 · 預測檢查通過

用 posterior 重新模擬資料的預測檢查，以及 holdout 評估，都必須在事先固定的門檻內。

5 · 中斷可以安全續跑

中斷續跑測試必須重現不中斷執行的最終輸出。

6 · 不輸給目前基準

新 SMC 的 predictive score 至少不能差於 active compound MCMC。
