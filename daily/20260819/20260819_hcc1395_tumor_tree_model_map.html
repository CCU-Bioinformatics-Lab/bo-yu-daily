04 / inference engine

推理演算法怎麼猜出參數

基本版只用 plain Metropolis–Hastings：輸入 observations，提議一個新 state，接受或拒絕，留下 posterior samples。
01

把資料變成機率

用 REF/ALT counts 建立 Binomial likelihood；HP counts 提供條件式分配。

30,006 eligible SNVs
02

產生參數候選

用 purity、CN、multiplicity 把 counts 轉成 CCF-aware 的預期 ALT fraction。

VAF → CCF-aware
03

提出一個新 state

一次改動一個 SNV assignment、η 或 tree topology，形成 proposal。

T / zᵢ / η
04

調整 clone 比例

更新 clone 的 exclusive fraction 與 cumulative prevalence，必要時調整分枝。

ηᵥ / ϕᵥ
05

接受或拒絕

比較新舊 state 的 posterior 與 proposal ratio；接受就移動，拒絕就留在 current。

plain MH · 4 chains
06

外部 QC 再判讀

R-hat、ESS、simulation、holdout 由外部 workflow 檢查；未通過仍只保留 candidate。

candidate / abstain
BASELINE · PLAIN MH每條 chain 以同一個 plain MH kernel 探索；完成後輸出 samples、代表樹與 diagnostics。

05 / methods background

Plain Metropolis–Hastings 一眼版

Likelihood 評分目前 state；MH proposal 產生候選；accept / reject 決定下一步；留下的 states 就是 posterior samples。
查看 target、prior 與 sampler 細節
L

Likelihood

計算目前參數能否解釋 REF/ALT、HP、CN 與 purity 觀測。

Binomial + HP conditional allocation
P

Tree prior

在資料之外，以自訂penalty對有限clone tree的深度與分枝給出偏好。

finite-K depth / branching penalty
I

Input

一列一個 SNV：Dᵢ、Hᵢ、Cᵢ、CN-only multiplicity prior、rho_ASCAT。

observed data + fixed parameters
MH

Metropolis–Hastings

從 current state 提議新 state，依 target posterior 與 proposal ratio 接受或拒絕。

single baseline sampler
O

Output

保留 burn-in 後的 current states；被拒絕時會重複上一個 state。

samples · representative_tree · diagnostics · checkpoint
QC

Diagnostics

R-hat、ESS、simulation 與 holdout 不會猜參數，只判斷 samples 能否採信。

convergence / abstention gate
一個 state 怎麼走一輪？MH = Metropolis–Hastings。
01

Current state

目前的 T、zᵢ、η 代表一個完整的候選解。

T + zᵢ + η → current
02

Proposal → score

只改動一個元件，重新計算 likelihood、prior 與 proposal ratio。

current → proposal → score
03

Accept / reject

接受候選就更新 current；拒絕候選就保留原 state，然後進入下一輪。

accept → new state · reject → same state
目前 baselinefinite-K tree prior + raw-count likelihood；以同一個 plain Metropolis–Hastings kernel 更新 T、zᵢ、η，burn-in 後的 retained states 形成 posterior samples。
一眼版結論 這是一個「原 HCC1395 tumor tree model + long-read evidence」的 plain MH baseline；輸出先以 posterior samples、代表樹與 diagnostics 描述。
