Inference background / why it is not plain MCMC

不是一個演算法，
而是一組更新方法

Likelihood + prior 先定義要找的 posterior；Gibbs 與 Metropolis–Hastings (MH) moves 再輪流探索它；最後用 diagnostics 判斷 samples 是否可信。

target = posteriorCN-only multiplicity priordiagnostics can abstain

Bayesian target

Likelihood 與 prior 組成 posterior；它不是抽樣器。

π(θ | D) ∝ L(D | θ) × P(θ)

Gibbs sampling

固定其他變數，從條件分布局部更新一個變數。

local conditional update

Metropolis–Hastings (MH)

提出候選狀態，再用 target 與 proposal correction 決定接受或拒絕。

proposal + Hastings correction

Diagnostics

不會猜參數；它檢查 chain 是否混合、是否值得摘要。

R-hat / ESS / simulation / holdout
01

Gibbs：大量局部離散更新

適合 SNV → clone assignment 這種大量離散變數，而且 conditional distribution 可以直接抽樣時。現在固定 T、η、π，重新抽 zᵢ。

fixed state → sample zᵢ · local move
02

MH：沒有簡單 conditional

Metropolis–Hastings 適合 tree topology 或 prevalence 沒有閉式條件分布時。現在提出 η / topology 候選，再用 target 與 forward/reverse proposal correction 決定接受或拒絕。

proposal → score → accept / reject
03

Eta bridge：較遠的連續跳轉

local eta random walk 移動太慢時，從固定 reference proposal 提出較遠候選；forward/reverse proposal density 都必須納入。

independent proposal → Hastings correction
目前實作的正確稱呼finite-K depth/branching prior + raw-count likelihood + Gibbs assignment + MH topology/prevalence + independent eta bridge；可視為 compound Metropolis-within-Gibbs。
一句話分工Likelihood 決定分數；Gibbs 做局部更新；MH 做候選跳轉；eta bridge 幫助較遠跳轉；diagnostics 決定能否採信。Split–merge 目前未實作。
