已收斂的研究決策

資料邊界

raw BAM、VCF、ASCAT 先整理成每顆 SNV 一列的 canonical input；主要觀測是 REF/ALT counts、site CN 與 sample purity rho_ASCAT。

Model A 邊界

major_cn、minor_cn、total_cn 與 rho_ASCAT 是主要 input；multiplicity 是 model 內部的 SNV-level candidate，不是外部 table 欄位。

結果語意

eta 是 local clone mass，phi 是 clone 加 descendants 的累積比例；topology、CCF/phi、SNV assignment 都先視為 candidate output。

權威定義請以 data.md、model.md、inference_algo.md 與 output.md 為準；daily 內容只作歷史導覽。
