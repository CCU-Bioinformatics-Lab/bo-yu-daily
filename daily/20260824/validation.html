VALIDATION MODULE · ELI5

validation：替腫瘤演化樹做「結果驗收」

model 和 inference_algo 負責產生候選樹；validation 像一位驗貨員，檢查這棵樹的資料、計算和外部證據，最後說明「目前最多能相信到哪裡」。這是 validation.md 的 MVP 規格視覺化，不是已完成的 validation 結果。

● MVP specification read-only：只檢查，不回寫 active: Rao–Blackwellized annealed SMC 不等於生物學真相

1. 它在整體研究裡的位置

validation 不會重新猜參數，也不會偷偷修改 likelihood。它只讀取 output 與相關紀錄。

2. MVP 的四個檢查站

先看推理是否健康，再看 clone 關係、可用的真值與資料預測。這四項不等於生物學真實性。

V1：SMC 健康嗎？

目前 active diagnostics

粒子有沒有全部擠成少數幾個？看 ESS、權重、resampling 和 topology diversity。

V2：clone 關係穩嗎？

規格／future artifact

把多個候選樹的權重合在一起，看 ancestor、descendant 和 branch 關係得到多少支持。

V3：有真值時重建對嗎？

synthetic only

只有 synthetic ground truth 存在時，才比較 V-measure 和 ancestor–descendant F1。

V4：能重現觀察訊號嗎？

conditional / aggregate gate

比較 observed 與 predicted VAF/ALT 訊號；observed VAF 是摘要，不是新的模型輸入。MVP 不設定 universal PASS threshold。

V1–V4 只能說明推理、關係、synthetic accuracy 或資料配適是否合理，不能單獨把樹變成 biological truth。

目前 workflow 的 coverage / log-score 是工程上的 fail-closed gate，不是生物學信心分數。

4. 檢查階梯：從檔案一路走到 claim

每一層都要先過，才可以往下一層。任何 core hard FAIL 都會把結論停在較低層級。

Gate 0–1run provenance、input schema、counts/CN/purity 是否完整資料身分
Gate 2SMC beta、particle ESS、resampling、rejuvenation、repeat 是否健康推理可靠性
Gate 3–5rooted tree、CCF/phi、SNV-to-clone assignment 是否合法輸出結構
Gate 6–7predictive check、必要時的 holdout，與 ASCAT/CN/LOH/ploidy 是否相容bulk evidence
Gate 8–11CNV-to-node、driver、topology stability、alternative uncertainty補充證據
Gate 12依所有結果決定最後能使用哪一種 claim wordingclaim ceiling

5. 「相容」不能直接變成「證明」

這是 validation 最重要的煞車。它避免我們把有限的 bulk 證據說得太滿。

目前可以說

  • 候選 tree 與 bulk CN/LOH/purity pattern 相容。
  • SMC particle population 通過指定的計算診斷。
  • 某些 edge 或 SNV assignment 在 repeats 中較穩定。

目前不能直接說

  • site-level CN 已證明 CNA 發生在某 branch。
  • 高 CCF 或圖上的 driver label 就是真實 driver-to-node truth。
  • 沒有 joint single-cell SNV+CN 就完成 single-cell lineage validation。

6. 目前 repo 的結論上限

validation 不會為了好看而給一個總分；它只回報目前證據能到哪裡。

CLAIM
CEILING

最高名稱： high-confidence candidate branching tree topology。

但目前 `output.md` 仍是 illustration，且沒有通過的 formal posterior 可供發布。因此現階段不能授予 Grade A；CNV event-to-node、driver mapping 與 single-cell lineage 仍是 optional 或 UNKNOWN。

candidate，不是唯一真相bulk compatibility，不是 branch proof

目前可讀取的 SMC artifacts

particle history、CCF/phi summary、topology summary、representative tree、multiplicity posterior、diagnostics 與 checkpoint。

尚未等於完成 validator

validation_report、evidence matrix、relationship posterior 與逐 SNV predictive residual table 仍是規格／future artifacts。

7. 一句話記住

validation 的工作不是替模型背書，而是把證據、未知和限制一起攤在桌上。

像驗貨員一樣思考

先確認貨物是正確的，再確認秤是正常的，再確認數字彼此吻合；最後才說這件貨「目前可以相信到什麼程度」。
