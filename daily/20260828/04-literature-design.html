文獻定位

沒有一篇論文逐字規定目前設計；它是有來源的 hybrid

文獻查核的結果不是「找到唯一正解」，而是把每個設計部件放回它最接近的方法家族，避免把 repo-specific choice 說成文獻原規格。

設計部件相近文獻／方法對本 repo 的意義今日結論
local mass → cumulative frequencyPhyloSub、PhyloWGS支持用 tree descendant sum 從 local clone fraction 得到 CCF／phi。採用
tree + frequency consistencyPairtree支持用頻率與樹關係共同限制候選解。參考
tree-aware Bayesian inferencePhyClone支持把 clone/tree configuration 放進後驗式推論框架。參考
tree priorTSSB可參考樹先驗與無限樹想法，但不等於本 repo 的固定 K state。不直接複製
multiplicity-aware emissionPyClone、PyClone-VI、PhyloWGS支持把 CN、purity、timing、multiplicity 放進觀測模型，而非只做 VAF 換算。落地
保留下來的核心
候選 tree 是結構；local mass 是 clone 自身比例；cumulative fraction 由 ancestry 決定；read-count likelihood 再檢查觀測是否合理。
不過度宣稱
目前 repo 不是 PhyClone、PyClone-VI 或 PhyloWGS 的完整 reproduction；正式 validation 還需要獨立 gate。
定位：文獻提供可追溯的構件與比較基準；本 repo 的 state decomposition 與輸出契約仍是自己的工程設計。
