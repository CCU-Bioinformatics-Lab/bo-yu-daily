術語與候選樹 state

一張「可能答案卡」：T、eta，再算出 phi

今天把容易混淆的三個量拆開：eta_v 是 clone 自身的 local fraction；phi_v／CCF 是 clone 加上後代的累積 fraction；T 決定哪些 clone 是後代。

候選答案卡上先記兩件事
T：猜測中的腫瘤樹
記錄 founder、clone 與 parent/child 關係。
eta_v：clone 自己的比例
只分給 clone v，不含 descendants；所有 local masses 形成 simplex。
T + eta → descendant sum → phi_v / CCF
例如某 clone 自身是 0.20，兩個後代合計 0.30；那麼該 clone 的 CCF／phi 約為 0.50。
不先放進持久 state
z（SNV 屬於哪個 clone）與 m（mutated copies）在 likelihood 中被 marginalize；summary 可輸出 MAP assignment 與 multiplicity posterior，但不把每種組合都塞進答案卡。
語意決策
canonical term 採用 clone-specific local fraction；不以 clonal prevalence 作為專案術語。CCF／phi 保持 cumulative meaning。
設計定位
T + eta → phi 有 PhyloSub／PhyloWGS 類似結構，Pairtree 也有相近的 tree/frequency constraint；但本 repo 的完整 candidate state 是 hybrid、repo-specific design。
一句話：候選樹負責提供演化關係，eta 負責分配 clone 自身比例，phi 是依樹關係計算出的累積比例。

CNV-aware emission

把 VAF 視為 emission 的結果：xi 不是直接換算器

今天確定採用 PhyClone／PyClone-VI-style 的 expected ALT probability，讓 purity、copy number、突變時序與 multiplicity 一起影響 read-count likelihood。

核心計算鏈
purity t
p_N=1−t
normal cells
CCF f
p_R=t(1−f)
reference tumor
variant mass
p_V=tf
variant tumor
xi_g(f) = genotype candidate 的 expected ALT fraction
對每個 genotype／timing candidate 計算 xi，再對候選 candidate marginalize，最後用 Binomial read-count likelihood 比較觀察到的 REF／ALT reads。
已定案的 state 邊界
multiplicity m 不成為 persistent candidate-tree state；它留在 likelihood 裡做 marginalization，並產生每個 SNV 的 posterior responsibility。
CNV timing
candidate 分開 mutation-before-CNV 與 mutation-after-CNV；不再把所有 VAF 偏差都壓成單一 multiplicity。
生物學邊界
CCF／phi 定義保留。疑似 mutation-loss 的 site 先當 outlier；精確判斷規則還沒有實作。
重要區分：PyClone-VI 不是把 observed VAF 直接轉成 CCF；xi 是在候選 clone fraction、purity、CN 與 genotype 下預測 ALT fraction 的 emission。
