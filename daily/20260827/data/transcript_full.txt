Frame → Preflight → Dispatch → Collect → Reconcile → Answer 簡單解釋流程

--- 🤖 ASSISTANT [2026-08-27T08:12:21.603Z] ---
這六步可以把它想成「先定義問題，再找證據，最後才下結論」：

1. **Frame｜框定問題**  
   先確認要查什麼、涉及哪個樣本／工具／檔案，以及要看目前狀態還是歷史紀錄。

2. **Preflight｜事前檢查**  
   確認三個資料來源能不能讀取，並先做一次 lab knowledge 的初步搜尋。

3. **Dispatch｜分派工作**  
   啟動至少兩個 subagent，分別搜尋 lab knowledge 與目前 repository；有歷史問題再加 history agent。

4. **Collect｜收集結果**  
   等所有 subagent 回報，整理它們找到的檔案、行號、結論與缺口。

5. **Reconcile｜比對核對**  
   比較不同來源是否衝突，主 agent 回頭讀原始檔，判斷哪些是目前事實、歷史資訊或推論。

6. **Answer｜回答**  
   先給結論，再附上來源路徑、證據狀態與尚未確認的部分。

簡化成一句話：

```text
定義問題 → 檢查資料 → 分工搜尋 → 收集證據 → 消除矛盾 → 有根據地回答
```

### Particle state

每顆 particle 真正保存的只有：

- `topology`：fixed-K、無環、只有一個 tumor founder 的 parent vector；

4. weighted ESS 低於門檻時做 systematic resampling，並記錄 ancestor diversity：`inference/src/algorithm.cpp:570-597`、`inference/src/algorithm.cpp:1010-1024`。

6. 到 `beta=1` 後再做 terminal systematic resampling，發布等權重 posterior particles：`inference/src/algorithm.cpp:1047-1055`。

你說得對，原句太抽象。實際評分流程是：

```text
candidate state = tree topology T + clone local mass eta
```

1. 由 `T + eta` 推導每個 clone 的 `phi/CCF`。
2. 對每個 SNV、每個 clone 和每個 multiplicity `m`，計算 expected ALT fraction：

```text
q_bulk =
  rho_ASCAT × phi × m
  -----------------------------
  (1-rho_ASCAT)×2 + rho_ASCAT×total_cn
```

3. 用 observed `REF/ALT reads` 做 Binomial likelihood：

```text
L_i(phi)
  = Σ_m P(m | CN) × Binomial(ALT_i | total_reads_i, q_bulk)
```

4. 用 clone 的 `eta` 混合各個 clone 對該 SNV 的解釋：

```text
L_i(T, eta)
  = Σ_v eta_v × L_i(phi_v)
```

5. 對所有 SNV 加總，得到 candidate tree 的 likelihood；再加上 tree prior 和 `eta` 的 Dirichlet prior，形成 posterior：

```text
posterior score
  = tree prior + eta prior + log likelihood
```

- `tree topology`：透過 prior 和所有 SNV likelihood 評分。
- `CCF/phi`：由 topology 和 `eta` 推導，不是獨立輸入。

目前 C++ runtime 的 baseline likelihood 可以濃縮成一句話：

> 對每一顆 SNV，模型用 `purity × CCF/phi × mutated-copy 數` 推算 ALT 比例，再用 Binomial likelihood 比較實際的 REF/ALT reads；multiplicity 與 SNV-to-clone assignment 都先邊際化。

## 1. 每顆 SNV 的輸入

對 SNV `i` 使用：

```text
ref_reads_i
alt_reads_i
total_reads_i
major_cn_i
minor_cn_i
total_cn_i
rho_ASCAT
```

HP counts 只做 schema/conservation check，不進 likelihood。

## 2. 建立 multiplicity candidates

每顆 SNV 都根據自己的 `major_cn/minor_cn` 建立可能的 mutated-copy 數：

```text
major_cn=3, minor_cn=1
→ multiplicity candidates = {1, 2, 3}
```

這不是 sample-level 單一值，而是每個 SNV 的候選集合與 prior。

## 3. 計算 expected ALT probability

對某個 clone `v`，令：

- `phi_v`：該 clone 及 descendants 的累積比例
- `m`：該 SNV 的候選 multiplicity
- `rho_ASCAT`：sample purity

C++ 實際使用：

\[
d_i=(1-\rho_{ASCAT})\times2+
\rho_{ASCAT}\times total\_cn_i
\]

\[
q_i(\phi_v,m)=
\operatorname{clamp}
\left(
\frac{\rho_{ASCAT}\times\phi_v\times m}{d_i},
10^{-12},1-10^{-12}
\right)
\]

其中 `2` 是 normal diploid copy number。

這代表：

```text
expected ALT probability
≈ purity × CCF × mutated copies
  ÷ normal DNA copies + tumor DNA copies
```

`10^-12` 只是數值安全限制，不是 sequencing error model。

## 4. 用 Binomial 評估 reads

令：

```text
A_i = alt_reads_i
N_i = total_reads_i
```

固定 `phi_v` 與 `m` 時：

\[
A_i\sim
\operatorname{Binomial}
\left(N_i,q_i(\phi_v,m)\right)
\]

因為 `m` 不確定，所以模型對 multiplicity 做邊際化：

\[
L_i(\phi_v)
=
\sum_{m\in M_i}
P_i(m\mid CN_i)
\operatorname{Binomial}
\left(A_i\mid N_i,q_i(\phi_v,m)\right)
\]

C++ 實作使用 log-sum-exp 計算，避免數值下溢。

## 5. 再對 clone assignment 邊際化

SNV 不直接固定分配給某個 clone，而是計算：

\[
\log L_i(T,\eta)
=
\log\sum_v
\left[
\eta_v L_i(\phi_v)
\right]
\]

因此目前 particle 只保存：

```text
tree topology + eta
```

`phi` 從 topology 和 `eta` 推導；SNV assignment 與 multiplicity 都是 Rao–Blackwellized latent quantities。
