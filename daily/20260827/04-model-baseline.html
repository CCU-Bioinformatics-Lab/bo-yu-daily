文件不再把未實作的 PhyClone-compatible `xi` 當成現行 runtime；目前 C++ baseline 以 CN-derived multiplicity candidates 與簡化 q likelihood 評分。

主要 features
輸入／狀態層級與用途
ref_reads、alt_reads、total_readsSNV-level observed counts
rho_ASCATsample-level purity
major_cn、minor_cn、total_cnsite-level CN context
M_i、pi_i(m)model 依 CN 產生的 latent candidates
語意核對
  • eta_v：clone local mass。
  • phi_v = eta_v + descendants(v)：cumulative CCF。
  • multiplicity 是每個 SNV 的 candidate，不是 sample-level 單值。
  • HP counts 只做 conservation／QC，不進 primary likelihood。
Current C++ baseline likelihood
N_i = ref_reads_i + alt_reads_i
d_i = (1-rho_ASCAT)*2 + rho_ASCAT*total_cn_i
q_i(phi_v,m) = clamp(rho_ASCAT*phi_v*m/d_i, 1e-12, 1-1e-12)
L_i(phi_v) = Σ_m pi_i(m) · Binomial(alt_reads_i | N_i, q_i)
log L(D|T,eta) = Σ_i log(Σ_v eta_v · L_i(phi_v))
實作使用 log-sum-exp。`M_i` 由該 SNV 的 major/minor CN 建立；`m` 是 SNV-level candidate。這段是 current baseline，和未同步的 `xi` target/spec 分開。
