下面是一筆「示意性的 PhyClone SNV input」。

### 1. PhyClone 輸入列

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr7:140453136:C>T	HCC1395	90	10	3	1	2	0.99	0.001	chr7
```

這些欄位的意義：

| 欄位 | 此例數值 | 意義 |
|---|---:|---|
| `mutation_id` | `chr7:140453136:C>T` | SNV 唯一識別 |
| `sample_id` | `HCC1395` | 樣本名稱 |
| `ref_counts` | 90 | 支持 REF 的 reads |
| `alt_counts` | 10 | 支持 ALT 的 reads |
| `major_cn` | 3 | tumor segment 的 major copy number |
| `minor_cn` | 1 | tumor segment 的 minor copy number |
| `normal_cn` | 2 | 正常組織該 segment 的 total CN |
| `tumour_content` | 0.99 | tumor cellularity |
| `error_rate` | 0.001 | sequencing-error floor |
| `chrom` | chr7 | 染色體 |

PhyClone 會推導：

```text
observed VAF = 10 / (90 + 10) = 0.10
total_cn = major_cn + minor_cn = 3 + 1 = 4
```

`observed VAF=0.10` 是從 reads 得到的觀察摘要，不是獨立輸入參數。

### 2. PhyClone 內部建立的 CN candidates

這筆 SNV 的 `major_cn=3`、`minor_cn=1`、`normal_cn=2`，因此：

```text
total_cn = 4
```

PhyClone 會建立以下 genotype/CN timing candidates：

| Candidate | CN tuple `(c_N,c_R,c_V)` | ALT fraction `(mu_N,mu_R,mu_V)` |
|---|---|---|
| pre-CN, m=1 | `(2,2,4)` | `(0.001,0.001,0.25)` |
| pre-CN, m=2 | `(2,2,4)` | `(0.001,0.001,0.50)` |
| pre-CN, m=3 | `(2,2,4)` | `(0.001,0.001,0.75)` |
| post-CN, m=1 | `(2,4,4)` | `(0.001,0.001,0.25)` |

其中：

- `c_N`：normal population 的 copy number
- `c_R`：沒有 mutation 的 tumor population 的 copy number
- `c_V`：帶有 mutation 的 tumor population 的 copy number
- `m`：ALT mutated-copy multiplicity
- `mu_N`、`mu_R`：normal/reference population 的 ALT error probability
- `mu_V`：variant population 的 ALT-copy fraction

官方程式通常對這些 candidates 使用 equal prior；此例有 4 個 candidates，因此每個初始 prior 約為：

```text
P(candidate) = 1/4 = 0.25
```

候選建立邏輯見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

### 3. 如何計算 expected VAF `xi`

假設模型目前考慮一個 CCF：

```text
CCF = 0.40
tumour_content = 0.99
```

三種 population weights：

```text
w_N = 1 - 0.99 = 0.01
w_R = 0.99 × (1 - 0.40) = 0.594
w_V = 0.99 × 0.40 = 0.396
```

PhyClone 使用：

```text
xi =
  (w_N*c_N*mu_N + w_R*c_R*mu_R + w_V*c_V*mu_V)
  ------------------------------------------------
           w_N*c_N + w_R*c_R + w_V*c_V
```

各 candidate 的 expected VAF：

| Candidate | `xi` |
|---|---:|
| pre-CN, m=1 | 0.1423 |
| pre-CN, m=2 | 0.2841 |
| pre-CN, m=3 | 0.4259 |
| post-CN, m=1 | 0.1001 |

這個示意中，observed VAF 是 `0.10`，而 post-CN candidate 的 `xi≈0.1001` 最接近。但 PhyClone 不會直接挑「最接近 observed VAF」的 candidate，而是計算：

```text
P(data | CCF)
  = sum_g P(g) × Binomial(ALT_count | total_count, xi_g)
```

也就是把所有 CN timing、multiplicity candidate 邊際化。

公式實作見 [math_utils.py:216](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/utils/math_utils.py:216)。

### 4. 這個 SNV 帶來什麼資訊？

這一筆 SNV 同時提供五種資訊：

1. **read-level allele evidence**

   ```text
   REF = 90
   ALT = 10
   observed VAF = 0.10
   ```

2. **tumor copy-number context**

   ```text
   major_cn = 3
   minor_cn = 1
   total_cn = 4
   ```

   表示 tumor segment 不是簡單 diploid 狀態。

3. **normal baseline**

   ```text
   normal_cn = 2
   ```

   表示正常組織該 segment 的 copy number，不能用 tumor `total_cn=4` 取代。

4. **CN timing uncertainty**

   SNV 可能發生在 CN gain 前，也可能發生在 CN gain 後，因此會產生不同的 expected VAF。

5. **對 CCF 的 likelihood 約束**

   這筆 SNV 會影響不同 CCF、multiplicity、CN timing candidate 的 posterior probability，但它不會單獨決定唯一 CCF。

下面是一筆「示意性的 PhyClone SNV input」。

### 1. PhyClone 輸入列

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr7:140453136:C>T	HCC1395	90	10	3	1	2	0.99	0.001	chr7
```

這些欄位的意義：

| 欄位 | 此例數值 | 意義 |
|---|---:|---|
| `mutation_id` | `chr7:140453136:C>T` | SNV 唯一識別 |
| `sample_id` | `HCC1395` | 樣本名稱 |
| `ref_counts` | 90 | 支持 REF 的 reads |
| `alt_counts` | 10 | 支持 ALT 的 reads |
| `major_cn` | 3 | tumor segment 的 major copy number |
| `minor_cn` | 1 | tumor segment 的 minor copy number |
| `normal_cn` | 2 | 正常組織該 segment 的 total CN |
| `tumour_content` | 0.99 | tumor cellularity |
| `error_rate` | 0.001 | sequencing-error floor |
| `chrom` | chr7 | 染色體 |

PhyClone 會推導：

```text
observed VAF = 10 / (90 + 10) = 0.10
total_cn = major_cn + minor_cn = 3 + 1 = 4
```

`observed VAF=0.10` 是從 reads 得到的觀察摘要，不是獨立輸入參數。

### 2. PhyClone 內部建立的 CN candidates

這筆 SNV 的 `major_cn=3`、`minor_cn=1`、`normal_cn=2`，因此：

```text
total_cn = 4
```

PhyClone 會建立以下 genotype/CN timing candidates：

| Candidate | CN tuple `(c_N,c_R,c_V)` | ALT fraction `(mu_N,mu_R,mu_V)` |
|---|---|---|
| pre-CN, m=1 | `(2,2,4)` | `(0.001,0.001,0.25)` |
| pre-CN, m=2 | `(2,2,4)` | `(0.001,0.001,0.50)` |
| pre-CN, m=3 | `(2,2,4)` | `(0.001,0.001,0.75)` |
| post-CN, m=1 | `(2,4,4)` | `(0.001,0.001,0.25)` |

其中：

- `c_N`：normal population 的 copy number
- `c_R`：沒有 mutation 的 tumor population 的 copy number
- `c_V`：帶有 mutation 的 tumor population 的 copy number
- `m`：ALT mutated-copy multiplicity
- `mu_N`、`mu_R`：normal/reference population 的 ALT error probability
- `mu_V`：variant population 的 ALT-copy fraction

官方程式通常對這些 candidates 使用 equal prior；此例有 4 個 candidates，因此每個初始 prior 約為：

```text
P(candidate) = 1/4 = 0.25
```

候選建立邏輯見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

### 3. 如何計算 expected VAF `xi`

假設模型目前考慮一個 CCF：

```text
CCF = 0.40
tumour_content = 0.99
```

三種 population weights：

```text
w_N = 1 - 0.99 = 0.01
w_R = 0.99 × (1 - 0.40) = 0.594
w_V = 0.99 × 0.40 = 0.396
```

PhyClone 使用：

```text
xi =
  (w_N*c_N*mu_N + w_R*c_R*mu_R + w_V*c_V*mu_V)
  ------------------------------------------------
           w_N*c_N + w_R*c_R + w_V*c_V
```

各 candidate 的 expected VAF：

| Candidate | `xi` |
|---|---:|
| pre-CN, m=1 | 0.1423 |
| pre-CN, m=2 | 0.2841 |
| pre-CN, m=3 | 0.4259 |
| post-CN, m=1 | 0.1001 |

這個示意中，observed VAF 是 `0.10`，而 post-CN candidate 的 `xi≈0.1001` 最接近。但 PhyClone 不會直接挑「最接近 observed VAF」的 candidate，而是計算：

```text
P(data | CCF)
  = sum_g P(g) × Binomial(ALT_count | total_count, xi_g)
```

也就是把所有 CN timing、multiplicity candidate 邊際化。

公式實作見 [math_utils.py:216](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/utils/math_utils.py:216)。

### 4. 這個 SNV 帶來什麼資訊？

這一筆 SNV 同時提供五種資訊：

1. **read-level allele evidence**

   ```text
   REF = 90
   ALT = 10
   observed VAF = 0.10
   ```

2. **tumor copy-number context**

   ```text
   major_cn = 3
   minor_cn = 1
   total_cn = 4
   ```

   表示 tumor segment 不是簡單 diploid 狀態。

3. **normal baseline**

   ```text
   normal_cn = 2
   ```

   表示正常組織該 segment 的 copy number，不能用 tumor `total_cn=4` 取代。

4. **CN timing uncertainty**

   SNV 可能發生在 CN gain 前，也可能發生在 CN gain 後，因此會產生不同的 expected VAF。

5. **對 CCF 的 likelihood 約束**

   這筆 SNV 會影響不同 CCF、multiplicity、CN timing candidate 的 posterior probability，但它不會單獨決定唯一 CCF。

```text
normal_cn = total copy number of the segment in healthy tissue
```

下面是一筆「示意性的 PhyClone SNV input」。

### 1. PhyClone 輸入列

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr7:140453136:C>T	HCC1395	90	10	3	1	2	0.99	0.001	chr7
```

這些欄位的意義：

| 欄位 | 此例數值 | 意義 |
|---|---:|---|
| `mutation_id` | `chr7:140453136:C>T` | SNV 唯一識別 |
| `sample_id` | `HCC1395` | 樣本名稱 |
| `ref_counts` | 90 | 支持 REF 的 reads |
| `alt_counts` | 10 | 支持 ALT 的 reads |
| `major_cn` | 3 | tumor segment 的 major copy number |
| `minor_cn` | 1 | tumor segment 的 minor copy number |
| `normal_cn` | 2 | 正常組織該 segment 的 total CN |
| `tumour_content` | 0.99 | tumor cellularity |
| `error_rate` | 0.001 | sequencing-error floor |
| `chrom` | chr7 | 染色體 |

PhyClone 會推導：

```text
observed VAF = 10 / (90 + 10) = 0.10
total_cn = major_cn + minor_cn = 3 + 1 = 4
```

`observed VAF=0.10` 是從 reads 得到的觀察摘要，不是獨立輸入參數。

### 2. PhyClone 內部建立的 CN candidates

這筆 SNV 的 `major_cn=3`、`minor_cn=1`、`normal_cn=2`，因此：

```text
total_cn = 4
```

PhyClone 會建立以下 genotype/CN timing candidates：

| Candidate | CN tuple `(c_N,c_R,c_V)` | ALT fraction `(mu_N,mu_R,mu_V)` |
|---|---|---|
| pre-CN, m=1 | `(2,2,4)` | `(0.001,0.001,0.25)` |
| pre-CN, m=2 | `(2,2,4)` | `(0.001,0.001,0.50)` |
| pre-CN, m=3 | `(2,2,4)` | `(0.001,0.001,0.75)` |
| post-CN, m=1 | `(2,4,4)` | `(0.001,0.001,0.25)` |

其中：

- `c_N`：normal population 的 copy number
- `c_R`：沒有 mutation 的 tumor population 的 copy number
- `c_V`：帶有 mutation 的 tumor population 的 copy number
- `m`：ALT mutated-copy multiplicity
- `mu_N`、`mu_R`：normal/reference population 的 ALT error probability
- `mu_V`：variant population 的 ALT-copy fraction

官方程式通常對這些 candidates 使用 equal prior；此例有 4 個 candidates，因此每個初始 prior 約為：

```text
P(candidate) = 1/4 = 0.25
```

候選建立邏輯見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

### 3. 如何計算 expected VAF `xi`

假設模型目前考慮一個 CCF：

```text
CCF = 0.40
tumour_content = 0.99
```

三種 population weights：

```text
w_N = 1 - 0.99 = 0.01
w_R = 0.99 × (1 - 0.40) = 0.594
w_V = 0.99 × 0.40 = 0.396
```

PhyClone 使用：

```text
xi =
  (w_N*c_N*mu_N + w_R*c_R*mu_R + w_V*c_V*mu_V)
  ------------------------------------------------
           w_N*c_N + w_R*c_R + w_V*c_V
```

各 candidate 的 expected VAF：

| Candidate | `xi` |
|---|---:|
| pre-CN, m=1 | 0.1423 |
| pre-CN, m=2 | 0.2841 |
| pre-CN, m=3 | 0.4259 |
| post-CN, m=1 | 0.1001 |

這個示意中，observed VAF 是 `0.10`，而 post-CN candidate 的 `xi≈0.1001` 最接近。但 PhyClone 不會直接挑「最接近 observed VAF」的 candidate，而是計算：

```text
P(data | CCF)
  = sum_g P(g) × Binomial(ALT_count | total_count, xi_g)
```

也就是把所有 CN timing、multiplicity candidate 邊際化。

公式實作見 [math_utils.py:216](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/utils/math_utils.py:216)。

### 4. 這個 SNV 帶來什麼資訊？

這一筆 SNV 同時提供五種資訊：

1. **read-level allele evidence**

   ```text
   REF = 90
   ALT = 10
   observed VAF = 0.10
   ```

2. **tumor copy-number context**

   ```text
   major_cn = 3
   minor_cn = 1
   total_cn = 4
   ```

   表示 tumor segment 不是簡單 diploid 狀態。

3. **normal baseline**

   ```text
   normal_cn = 2
   ```

   表示正常組織該 segment 的 copy number，不能用 tumor `total_cn=4` 取代。

4. **CN timing uncertainty**

   SNV 可能發生在 CN gain 前，也可能發生在 CN gain 後，因此會產生不同的 expected VAF。

5. **對 CCF 的 likelihood 約束**

   這筆 SNV 會影響不同 CCF、multiplicity、CN timing candidate 的 posterior probability，但它不會單獨決定唯一 CCF。

### 5. 對你目前 repo 的對應

```text
目前 repo major_cn       → PhyClone major_cn
目前 repo minor_cn       → PhyClone minor_cn
目前 repo total_cn       → major_cn + minor_cn
目前 repo rho_ASCAT     → 暫時對應 tumour_content
目前 repo 缺少           → normal_cn
目前 repo 缺少 runtime   → tumour_content / error_rate
```

因此你目前 repo 的單一 SNV 還不能直接視為完整 PhyClone input。最重要的缺口是 `normal_cn`；它必須來自 matched normal／healthy tissue 的 CN context，而不是由 tumor CN 或 `rho_ASCAT` 推導。

PhyClone 的 CNV 不是直接輸入一個獨立 BED；它需要先把 CNV segment 投影到每個 mutation/sample row。

最小主輸入：

| 欄位 | 必要性 | 意義 |
|---|---|---|
| `major_cn` | 必要 | mutation 所在 segment 的 major copy number |
| `minor_cn` | 必要 | minor copy number |
| `normal_cn` | 必要 | 正常組織 copy number，常染色體通常為 2 |
| `tumour_content` | optional | tumor cellularity，缺省為 `1.0` |
| `error_rate` | optional | sequencing error，缺省為 `0.001` |
| `chrom` | optional | chromosome |

此外還需要：

```text
mutation_id
sample_id
ref_counts
alt_counts
major_cn
minor_cn
normal_cn
tumour_content
error_rate
chrom
```

範例：

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr1:100:A>T	HCC1395	90	10	3	1	2	0.99	0.001	chr1
```

PhyClone 會自行推導：

```text
total_cn = major_cn + minor_cn
```

並建立 CN timing genotype candidates：

```text
mutation before CN event:
  c_N = normal_cn
  c_R = normal_cn
  c_V = total_cn
  ALT copies = 1 ... major_cn

mutation after CN event:
  c_N = normal_cn
  c_R = total_cn
  c_V = total_cn
  ALT copies = 1
```

--- 🤖 ASSISTANT [2026-08-26T00:09:01.331Z] ---
PhyClone 的 `normal_cn` 精確定義是：

> mutation 所在 CN segment，在健康／正常組織中的「總 copy number」。

它不是：

- tumor 的 `total_cn`
- tumor 的 `major_cn` 或 `minor_cn`
- tumor purity
- `tumour_content`
- `rho_ASCAT`
- mutation 的 ALT-copy 數

官方定義：

```text
normal_cn = total copy number of the segment in healthy tissue
```

官方預設：

```text
autosome          normal_cn = 2
male sex chromosome normal_cn = 1
```

來源：[PhyClone README:97](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/README.md:97)。

在 schema 中，`normal_cn` 是必要欄位，必須是 integer 且 `>= 1`：[PhyClone_schema.json:37](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/validator/PhyClone_schema.json:37)。

它會參與 CN timing candidate：

```text
total_cn = major_cn + minor_cn

mutation before CN event:
  c_N = normal_cn
  c_R = normal_cn
  c_V = total_cn

mutation after CN event:
  c_N = normal_cn
  c_R = total_cn
  c_V = total_cn
```

也就是說，`normal_cn` 用來表示「CN 改變前的正常基線」，而 `major_cn/minor_cn` 表示 mutation 所在 tumor segment 的 CN。官方實作見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

對你目前 repo：

```text
major_cn   → tumor segment major CN
minor_cn   → tumor segment minor CN
total_cn   → tumor total CN
rho_ASCAT  → purity，不是 normal_cn
```

目前 repo 沒有 `normal_cn`。HCC1395 tumor 是 hyper-diploid，也不能因此把 `normal_cn` 設成 2.85；`normal_cn` 應代表 matched normal／健康組織的 segment CN。若是一般 autosomal region，可暫用 `normal_cn=2`，但這是資料假設，最好由 HCC1395BL 的 normal CN segment 驗證。

下面是一筆「示意性的 PhyClone SNV input」。

### 1. PhyClone 輸入列

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr7:140453136:C>T	HCC1395	90	10	3	1	2	0.99	0.001	chr7
```

這些欄位的意義：

| 欄位 | 此例數值 | 意義 |
|---|---:|---|
| `mutation_id` | `chr7:140453136:C>T` | SNV 唯一識別 |
| `sample_id` | `HCC1395` | 樣本名稱 |
| `ref_counts` | 90 | 支持 REF 的 reads |
| `alt_counts` | 10 | 支持 ALT 的 reads |
| `major_cn` | 3 | tumor segment 的 major copy number |
| `minor_cn` | 1 | tumor segment 的 minor copy number |
| `normal_cn` | 2 | 正常組織該 segment 的 total CN |
| `tumour_content` | 0.99 | tumor cellularity |
| `error_rate` | 0.001 | sequencing-error floor |
| `chrom` | chr7 | 染色體 |

PhyClone 會推導：

```text
observed VAF = 10 / (90 + 10) = 0.10
total_cn = major_cn + minor_cn = 3 + 1 = 4
```

`observed VAF=0.10` 是從 reads 得到的觀察摘要，不是獨立輸入參數。

### 2. PhyClone 內部建立的 CN candidates

這筆 SNV 的 `major_cn=3`、`minor_cn=1`、`normal_cn=2`，因此：

```text
total_cn = 4
```

PhyClone 會建立以下 genotype/CN timing candidates：

| Candidate | CN tuple `(c_N,c_R,c_V)` | ALT fraction `(mu_N,mu_R,mu_V)` |
|---|---|---|
| pre-CN, m=1 | `(2,2,4)` | `(0.001,0.001,0.25)` |
| pre-CN, m=2 | `(2,2,4)` | `(0.001,0.001,0.50)` |
| pre-CN, m=3 | `(2,2,4)` | `(0.001,0.001,0.75)` |
| post-CN, m=1 | `(2,4,4)` | `(0.001,0.001,0.25)` |

其中：

- `c_N`：normal population 的 copy number
- `c_R`：沒有 mutation 的 tumor population 的 copy number
- `c_V`：帶有 mutation 的 tumor population 的 copy number
- `m`：ALT mutated-copy multiplicity
- `mu_N`、`mu_R`：normal/reference population 的 ALT error probability
- `mu_V`：variant population 的 ALT-copy fraction

官方程式通常對這些 candidates 使用 equal prior；此例有 4 個 candidates，因此每個初始 prior 約為：

```text
P(candidate) = 1/4 = 0.25
```

候選建立邏輯見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

### 3. 如何計算 expected VAF `xi`

假設模型目前考慮一個 CCF：

```text
CCF = 0.40
tumour_content = 0.99
```

三種 population weights：

```text
w_N = 1 - 0.99 = 0.01
w_R = 0.99 × (1 - 0.40) = 0.594
w_V = 0.99 × 0.40 = 0.396
```

PhyClone 使用：

```text
xi =
  (w_N*c_N*mu_N + w_R*c_R*mu_R + w_V*c_V*mu_V)
  ------------------------------------------------
           w_N*c_N + w_R*c_R + w_V*c_V
```

各 candidate 的 expected VAF：

| Candidate | `xi` |
|---|---:|
| pre-CN, m=1 | 0.1423 |
| pre-CN, m=2 | 0.2841 |
| pre-CN, m=3 | 0.4259 |
| post-CN, m=1 | 0.1001 |

這個示意中，observed VAF 是 `0.10`，而 post-CN candidate 的 `xi≈0.1001` 最接近。但 PhyClone 不會直接挑「最接近 observed VAF」的 candidate，而是計算：

```text
P(data | CCF)
  = sum_g P(g) × Binomial(ALT_count | total_count, xi_g)
```

也就是把所有 CN timing、multiplicity candidate 邊際化。

公式實作見 [math_utils.py:216](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/utils/math_utils.py:216)。

### 4. 這個 SNV 帶來什麼資訊？

這一筆 SNV 同時提供五種資訊：

1. **read-level allele evidence**

   ```text
   REF = 90
   ALT = 10
   observed VAF = 0.10
   ```

2. **tumor copy-number context**

   ```text
   major_cn = 3
   minor_cn = 1
   total_cn = 4
   ```

   表示 tumor segment 不是簡單 diploid 狀態。

3. **normal baseline**

   ```text
   normal_cn = 2
   ```

   表示正常組織該 segment 的 copy number，不能用 tumor `total_cn=4` 取代。

4. **CN timing uncertainty**

   SNV 可能發生在 CN gain 前，也可能發生在 CN gain 後，因此會產生不同的 expected VAF。

5. **對 CCF 的 likelihood 約束**

   這筆 SNV 會影響不同 CCF、multiplicity、CN timing candidate 的 posterior probability，但它不會單獨決定唯一 CCF。

### 5. 對你目前 repo 的對應

```text
目前 repo major_cn       → PhyClone major_cn
目前 repo minor_cn       → PhyClone minor_cn
目前 repo total_cn       → major_cn + minor_cn
目前 repo rho_ASCAT     → 暫時對應 tumour_content
目前 repo 缺少           → normal_cn
目前 repo 缺少 runtime   → tumour_content / error_rate
```

因此你目前 repo 的單一 SNV 還不能直接視為完整 PhyClone input。最重要的缺口是 `normal_cn`；它必須來自 matched normal／healthy tissue 的 CN context，而不是由 tumor CN 或 `rho_ASCAT` 推導。

官方輸入欄位定義見 [PhyClone README:73](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/README.md:73)。

下面是一筆「示意性的 PhyClone SNV input」。

### 1. PhyClone 輸入列

```tsv
mutation_id	sample_id	ref_counts	alt_counts	major_cn	minor_cn	normal_cn	tumour_content	error_rate	chrom
chr7:140453136:C>T	HCC1395	90	10	3	1	2	0.99	0.001	chr7
```

這些欄位的意義：

| 欄位 | 此例數值 | 意義 |
|---|---:|---|
| `mutation_id` | `chr7:140453136:C>T` | SNV 唯一識別 |
| `sample_id` | `HCC1395` | 樣本名稱 |
| `ref_counts` | 90 | 支持 REF 的 reads |
| `alt_counts` | 10 | 支持 ALT 的 reads |
| `major_cn` | 3 | tumor segment 的 major copy number |
| `minor_cn` | 1 | tumor segment 的 minor copy number |
| `normal_cn` | 2 | 正常組織該 segment 的 total CN |
| `tumour_content` | 0.99 | tumor cellularity |
| `error_rate` | 0.001 | sequencing-error floor |
| `chrom` | chr7 | 染色體 |

PhyClone 會推導：

```text
observed VAF = 10 / (90 + 10) = 0.10
total_cn = major_cn + minor_cn = 3 + 1 = 4
```

`observed VAF=0.10` 是從 reads 得到的觀察摘要，不是獨立輸入參數。

### 2. PhyClone 內部建立的 CN candidates

這筆 SNV 的 `major_cn=3`、`minor_cn=1`、`normal_cn=2`，因此：

```text
total_cn = 4
```

PhyClone 會建立以下 genotype/CN timing candidates：

| Candidate | CN tuple `(c_N,c_R,c_V)` | ALT fraction `(mu_N,mu_R,mu_V)` |
|---|---|---|
| pre-CN, m=1 | `(2,2,4)` | `(0.001,0.001,0.25)` |
| pre-CN, m=2 | `(2,2,4)` | `(0.001,0.001,0.50)` |
| pre-CN, m=3 | `(2,2,4)` | `(0.001,0.001,0.75)` |
| post-CN, m=1 | `(2,4,4)` | `(0.001,0.001,0.25)` |

其中：

- `c_N`：normal population 的 copy number
- `c_R`：沒有 mutation 的 tumor population 的 copy number
- `c_V`：帶有 mutation 的 tumor population 的 copy number
- `m`：ALT mutated-copy multiplicity
- `mu_N`、`mu_R`：normal/reference population 的 ALT error probability
- `mu_V`：variant population 的 ALT-copy fraction

官方程式通常對這些 candidates 使用 equal prior；此例有 4 個 candidates，因此每個初始 prior 約為：

```text
P(candidate) = 1/4 = 0.25
```

候選建立邏輯見 [pyclone.py:324](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/data/pyclone.py:324)。

### 3. 如何計算 expected VAF `xi`

假設模型目前考慮一個 CCF：

```text
CCF = 0.40
tumour_content = 0.99
```

三種 population weights：

```text
w_N = 1 - 0.99 = 0.01
w_R = 0.99 × (1 - 0.40) = 0.594
w_V = 0.99 × 0.40 = 0.396
```

PhyClone 使用：

```text
xi =
  (w_N*c_N*mu_N + w_R*c_R*mu_R + w_V*c_V*mu_V)
  ------------------------------------------------
           w_N*c_N + w_R*c_R + w_V*c_V
```

各 candidate 的 expected VAF：

| Candidate | `xi` |
|---|---:|
| pre-CN, m=1 | 0.1423 |
| pre-CN, m=2 | 0.2841 |
| pre-CN, m=3 | 0.4259 |
| post-CN, m=1 | 0.1001 |

這個示意中，observed VAF 是 `0.10`，而 post-CN candidate 的 `xi≈0.1001` 最接近。但 PhyClone 不會直接挑「最接近 observed VAF」的 candidate，而是計算：

```text
P(data | CCF)
  = sum_g P(g) × Binomial(ALT_count | total_count, xi_g)
```

也就是把所有 CN timing、multiplicity candidate 邊際化。

公式實作見 [math_utils.py:216](/bip8_disk/boyu114/main_work/research/phyclone/PhyClone/phyclone/utils/math_utils.py:216)。

### 4. 這個 SNV 帶來什麼資訊？

這一筆 SNV 同時提供五種資訊：

1. **read-level allele evidence**

   ```text
   REF = 90
   ALT = 10
   observed VAF = 0.10
   ```

2. **tumor copy-number context**

   ```text
   major_cn = 3
   minor_cn = 1

   ```
