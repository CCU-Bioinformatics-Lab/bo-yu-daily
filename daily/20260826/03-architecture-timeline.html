架構說明

研究生產線：每一站只做自己的工作，workflow 負責叫停

架構報告把 `arch.md` 的核心模組翻成白話：data input 整理材料，model 定義評分，inference 找候選，output 整理結果；validation 只讀證據，workflow 管理整條線。

data input
把 BAM／VCF／CNV／purity 整理成每個 SNV 一張小卡。
交給 model
model
定義「哪個候選答案比較能解釋 reads」的規則。
給 inference 評分
inference_algo
提出很多樹、比例和 assignment，再請 model 評分。
目前是 annealed SMC
output
把候選樹翻成 topology、CCF、SNV 歸屬等 artifacts。
仍是候選答案
validation：讀取各站證據，設定「現在最多能說到哪裡」
experiment_workflow 是上面的工廠經理：安排 build → smoke → pilot → formal、留下 receipts、遇到 gate 不足就停止；它不重寫 model，也不替 validation 做科學判定。
