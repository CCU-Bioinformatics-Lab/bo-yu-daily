# 假設、限制與失敗情境

## 生物學假設

1. [明示 STATED] **樹內 SNV 遵循 ISA 遺傳。** 在節點 `v` 產生的突變會存在於其所有後代；其 CCF 等於以該節點為根的整個子樹（包含該節點本身及所有後代）中克隆質量的總和。（Main Introduction pp.1–2; §2.2 p.3。）
2. [明示 STATED] **同一節點／叢集內具有共同歷史。** 被指派至同一群的突變共享相同的起源／演化歷史。（Main §2.1, p.2。）
3. [明示 STATED] **相關樣本共享同一套系譜。** 各樣本有各自的盛行率向量，但共享同一個分割與樹。（Main §2.2 p.3; Supplement Fig.S2 p.12。）
4. [明示 STATED] **三族群基因座模型。** 對一個 SNV 而言，細胞被視為正常、腫瘤參考型或腫瘤變異型，且每個子族群內的基因型固定不變。（Supplement S1.1 p.1。）
5. [推論 INFERRED] **離群值不等同於具因果意義的流失。** 同一狀態可以吸收缺失、CN 錯誤、比對／計數錯誤或其他不相容情況；模型不會推論發生缺失的分支，也不會推論突變重複發生事件。

## 統計假設

1. [明示 STATED] 分割遵循 CRP；調整前的拓樸在有根森林上呈均勻分布；最終狀態再加入強度為 `C=1000` 的單根偏好。（Supplement S1.3–S1.3.1 pp.2–4。）
2. [明示 STATED／實作 IMPLEMENTED] 盛行率遵循對稱 Dirichlet 分布；程式碼僅實作 `kappa=1`。（Supplement S1.3–S1.5; `tree/utils.py`。）
3. [明示 STATED] 給定樹、指派與盛行率後，各突變在概似中條件獨立。（Main §2.2 p.3。）
4. [明示 STATED] 在固定 CN／純度及列舉的基因型狀態條件下，等位基因計數遵循二項／Beta-Binomial PyClone 發射分布。（Supplement S1.1–S1.2。）
5. [明示 STATED] 離群值 CCF 採均勻先驗，每筆資料的 Bernoulli 先驗為 `nu`；[實作 IMPLEMENTED] 預分群採全有或全無方式，而其對數先驗會乘上叢集大小。
6. [推論 INFERRED] `alpha`、網格解析度、根節點懲罰與離群值先驗，都可能實質影響節點數、拓樸與排除結果，但研究未提供廣泛的敏感度分析。
7. [推論 INFERRED] 以概似加權的後驗指標及共用的 PhyClone LPR 評估器可提供一致性，但仍可能偏好與 PhyClone 共用的假設。

## 計算假設

1. [明示 STATED] WGS 規模的工作在實務上需要預分群；未分群資料的計算複雜度會急遽上升。（Main §2.2.2 p.3。）
2. [明示 STATED] 固定順序 SMC 無法到達所有樹；必須使用輔助順序 PG。（Main §2.3.1 p.4。）
3. [推論 INFERRED] 理論上的可到達性不代表有限鏈具有足夠的混合效果。目前預設為一條鏈，而 README 建議至少使用四條。
4. [明示 STATED／實作 IMPLEMENTED] 全調適式（fully adapted）提議的成本會隨目前根節點數呈指數成長；半調適式方法只抽樣一個子集，以提議品質換取較低成本。
5. [明示 STATED] DP 成本取決於節點、突變、樣本、網格與出度：`O(V(NL+CSL²))`。（Supplement S1.5 p.5。）
6. [實作 IMPLEMENTED] 101 點網格、有限快取與可選的 FFT 都是效能上的選擇；結果仍經離散化。
7. [明示 STATED／實作 IMPLEMENTED] 論文試驗設有 48 小時上限。目前簽出版本有應用程式層級的 `--max-time` 停止機制，但缺少基準測試的逾時前處理，以及缺失值／懲罰處理；因此無法由此儲存庫重現論文的 48 小時結果。

## 資料集與評估假設

1. [明示 STATED] 合成資料先以 PyClone-VI 預分群；上述五種後續階段方法——CONIPHER、Pairtree、Orchard、fastBE 與 PhyClone——共用這些預分群。TSSB-Low 的 PhyloWGS 比較並未採用相同的前處理，因為文中未將 PhyloWGS 列為接收預分群結果的方法。HGSOC 則共用原始研究的叢集。因此，對這五種方法而言，樹建構器效果是以共用前處理階段為條件的結果。
2. [明示 STATED] V/AD 使用選定的點估計樹；RRE/LPR 使用加權後的不重複解。單一 MAP 樹可能掩蓋多峰性。
3. [明示 STATED] RRE 需要符合完美系譜的真值，因此在 CONIPHER 資料集中省略。
4. [明示 STATED] HGSOC 評估會移除不參與定義真值的突變，並折疊因此變空的節點，這可能掩蓋過度解析的情況。
5. [推論 INFERRED] 失敗懲罰（點估計準確度為 0、後驗指標為 1/1.5）會影響統計對比；完整案例的描述性平均值並非檢定所使用的平均值。
6. [推論 INFERRED] Pairtree 基準測試是不完整的全因子網格，合併結果僅適用於保留的條件。

## 作者明述的限制

- 整體腫瘤定序即使跨區域取樣，也只能部分識別拓樸。（Main Introduction pp.1–2。）
- 突變流失違反基本的 ISA／可加性。（Main Introduction p.2; §3.1 p.6。）
- 底層 PyClone 基因型校正無法為亞克隆 CNV 區域建模。（Main Discussion p.8。）
- 若沒有 Particle Gibbs，固定 SMC 順序會限制可到達的樹。（Main §2.3.1 p.4。）
- 未經預分群而直接處理 WGS，在計算上相當困難。（Main §2.2.2 p.3。）
- FS-CRP 流失消融實驗刻意偏向有利於 PhyClone 的設定。（Main §3.1 p.6。）

## 推論出的限制

- [推論 INFERRED] 預分群中的錯誤合併會形成不可突破的解析度上限，因為 PhyClone 無法將其拆分。
- [推論 INFERRED] 標記為離群值的突變會失去系譜位置；具有重要生物意義的流失事件只會被表示為排除。
- [推論 INFERRED] 強烈的根節點懲罰可能凌駕薄弱的資料證據，並低估真正的多根不確定性。
- [推論 INFERRED] 錯誤的純度／CN 可能產生信心很高但其實錯誤的 CCF 證據；系統性錯誤未必會呈現為離群值。
- [推論 INFERRED] 粗網格會使計分／盛行率產生偏差；細網格則會提高卷積成本。
- [推論 INFERRED] 共識／MAP 輸出會壓縮後驗不確定性，且匯出的盛行率不含區間。
- [推論 INFERRED] HGSOC 僅有三位病人，且最有力的流失證據只來自其中一個案例，無法支持廣泛的臨床推論。

## 實作層級的限制與衝突

1. **已發表公式／實作中的離群值不一致——UNRESOLVED（未釐清）。** 論文發表的是單一均勻積分，但 0.7.0 與 0.8.0 計算的是三角形雙重總和。常數被積函數的正規化檢查未通過。
2. **子樹 PG——UNRESOLVED（未釐清）。** 原始碼中的 TODO 質疑是否缺少子樹選取機率；預設為關閉。
3. **目前 bootstrap＋離群值——已確認為 0.8.0 迴歸問題。** 抽樣的分支質量與記錄的提議質量不同；論文採用的半調適式路徑不受影響。
4. **CLI/API 分歧。** 暖身／迭代次數／精度與流失機制是否啟用均有差異；關鍵參數應明確指定。
5. **輸入一致性的邊界案例。** 主要輸入與叢集檔案中的突變集合未受到穩健的交叉驗證；格式錯誤的重複／樣本模式可能導致資料遺漏或錯位。
6. **驗證缺口。** 目前的 Python／相依套件環境無法執行完整測試，且未附論文評估管線。

## 失敗情境矩陣

| 情況 | 可能失敗的原因 | 證據／緩解方式 |
|---|---|---|
| 克隆數遠多於具資訊性的樣本數 | 許多同層／祖先結構都符合盛行率限制 | Main §3.3; Figs.S12–S13。增加獨立樣本，或降低主張上限。 |
| 預分群錯誤合併 | 原子性的 `DataPoint` 無法拆分 | Main §2.2.2; `data/pyclone.py:82-115`。改善分群或事前稽核。 |
| 亞克隆或錯誤的 CN | 發射分布假設固定的克隆性基因座基因型候選集合 | Main Discussion p.8; S1.1–S1.2。排除／標記受影響區域，或使用更豐富的 CN 模型。 |
| 腫瘤純度錯誤 | 所有基因座的預期 VAF 都會偏移 | `math_utils.py:179-244`；缺少輸入時會無提示地預設為 1.0。提供經驗證的純度。 |
| 深度低／突變少 | 寬廣的發射分布使多棵樹皆與資料相容 | 概似結構。除了 MAP，也應報告後驗替代解。 |
| `nu` 高 | 相容但含雜訊的證據可能遭到丟棄 | 離群值 Bernoulli 先驗。進行先驗敏感度分析。 |
| `nu` 低 | 流失／錯誤資料可能扭曲分群／拓樸 | Fig.2/S4。檢查後驗離群值數量及敏感度。 |
| 明確詢問流失邊 | 模型沒有流失邊變數 | Main §2.2.3 與容器 `-1`。使用其他機制式模型，或改以不相容性描述。 |
| 目前森林有許多根節點 | 全調適式提議成本為 `2^R`；根節點懲罰可能主導結果 | S1.6.2/code。採用半調適式方法，並診斷根節點／混合狀況。 |
| 深樹／長序列 | PG 系譜退化會使早期結構凍結 | S1.6.4。使用多條鏈；子樹 PG 原本用來改善此問題，但目前仍未釐清。 |
| 0.8.0 的 bootstrap＋離群值 | 提議／log-q 權重不正確 | current `bootstrap.py`；修正前應避免使用此路徑。 |
| 後驗多峰性 | MAP／共識會掩蓋互相競爭的拓樸 | HDF5/topology report。報告多個拓樸的權重。 |
| CN 擾動詮釋 | S14 缺少條件標籤 | 不得由 XLSX 主張特定條件的數值趨勢。 |
| 逾時／缺失解 | 懲罰方式會改變比較結果 | S2/S3/S5/S28/S31/S34。報告失敗案例與懲罰慣例。 |

## 實務上的證據上限

最恰當的描述是：PhyClone 是一套具拓樸感知能力的貝葉斯解卷積系統；在輸入 CN／純度與預分群適當的條件下，它通常相當準確，也能穩健處理某些不相容突變。它不是明確的突變流失歷史模型，無法消除部分可識別性問題，而且就絕對成本而言並不便宜。
