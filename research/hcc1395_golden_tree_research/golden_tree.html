Confidence labels 的讀法

HighConf + MedConf 才組成後續使用的 somatic reference call set；LowConf 與 Unclassified 不應被讀成高可信度突變。

03 · methods have different jobs

四種分析，不是四個同義詞

把「產生樹」與「確認異質性」分開，才不會把 single-cell CNV heatmap 誤稱為 SNV lineage truth。

PhyloWGS

論文用 bulk clonality evidence 產生 high-confidence candidate branching tree topology。完整 input、參數與 posterior summary 未在本文公開。

SuperFreq

用 capture WES、VAF、local copy number 與 uncertainty 做 clonality clustering；是 bulk cross-check。

ASCAT + subHMM

確認 ploidy、LOH 與 clonal/subclonal CNA；不是直接輸出 SNV tree branch。

10x single-cell CNV

顯示每個細胞的 CNV profile 與異質性；不是每個 SNV 的單細胞 assignment。

04 · validation is layered

哪些是直接驗證？哪些只是支持？

同一個數字只放在它真正能支持的層級，避免把 call-set rate 變成 topology rate。

DIRECTLY TESTED

Mutation call credibility

  • AmpliSeq、Ion Torrent WES、HiSeq WES 與 PacBio 交叉確認 SNV / indel。
  • HighConf + MedConf：可判讀 SNV 1,417 / 1,418 = 99.93%。
  • titration：100%、75%、50%、20%、10%、5%、0% purity 檢查 VAF 隨 tumor fraction 的行為。
  • GATK CallableLoci 與多數決建立 consensus-callable regions。
SUPPORTIVE CORROBORATION

Tree / heterogeneity plausibility

  • SuperFreq 也觀察到 clonal / subclonal population。
  • ASCATNgs、subHMM、karyotype / CytoScan 支持複雜 CNV、LOH 與約 99% purity。
  • 10x：HCC1395 1,270 cells、HCC1395BL 638 cells 的 single-cell CNV pattern。
  • 這些證據支持「存在異質性與 branching model」，不是逐條驗證 high-confidence candidate branching tree topology 的 edge。

05 · claim boundary

最容易講錯的三件事

這一段把六份 Markdown 的 reviewer conclusion 壓成三個視覺化判斷。

Call-set ≠ tree truth

99.93% 是可判讀 SNV call 的確認率，不是每條 branch 的 posterior support。

CNV heatmap ≠ SNV lineage

10x 單細胞資料支持 CNV heterogeneity，不能直接回答哪個細胞帶有 S2 或 S8 的 SNV。

branching 是 model result

作者用 inferred / suggests branching；不能把 S1–S10 宣稱成已逐節點觀察到的唯一祖先樹。

最精確的一句話

HCC1395 存在一個由多平台 mutation evidence、bulk clonality、CNV 與 single-cell CNV 共同支持的 branching clonal model；其命名為 high-confidence candidate branching tree topology，不是已被逐節點證明的 lineage ground truth。
