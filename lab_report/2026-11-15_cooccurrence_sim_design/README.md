## 1. 最重要的發現：先修評分，再改模擬器

haploclone 的共現評分（`haploclone/rust/src/pairs.rs:217-224`）對每一對 SNV 各自積分一個 Beta 比例。每多一對沒有「只帶祖先突變」read 的 SNV 對，「祖先」這個關係就被扣約 ln(read 數＋1) 分。

- HG008 truncal × L111 的 20 對（n11 150、n10 10、n01 2）〔實測〕`../2026-11-15_hg008_snv_pairs/truncal_L111_same_hp.txt`：
  - 現行逐對評分，eps 0.01：祖先 − 同一群 ＝ **−12.6**（偏向同一群）〔推論，我重算〕。
  - 20 對共用一個比例：**+7.0**（偏向分開）〔推論，我重算〕。
- 模擬（t 0.9、無錯誤）：CCF 差 ≤ 0.05 的祖先／子代，用現行評分給 1,000 對也分不開；共用比例時約 20 對就夠〔模擬〕`evidence/power.py`、`evidence/pooled.py`。
- 共用比例的風險：錯誤率高於 eps 時，假的 10 read 會造成假分群（錯誤率 2%、eps 0.01、200 對時，誤判率 0.74）〔模擬〕。所以 eps 要接近實際錯誤率，或用 01 read 的比例估錯誤率（祖先關係下 01 只會來自錯誤）。

**意義：** 照現行評分去模擬，結果「分不開」會來自評分，不是資訊不夠。所以先修評分，再改模擬器。

## 3. 跨過幾條 read：用 read 長度分布

- HG008 ONT read（reference span）：中位數 22.9 kb、N50 36.0 kb、> 50 kb 只有 5.2%〔實測〕`evidence/t3_readlen.txt`。
- 「跨過的 read 數 ＝ 深度 × S(d)，S(d) ＝ E[(L − d)+] ／ E[L]」不需要任何調整參數，就重現了 HG008 有標籤 SNV 對的實際 read 數（例：10–20 kb 觀測 29.6、預測 29.2）〔實測〕`evidence/t4_with_zero_pairs.txt`。
- **建議：** read 長度用分布，不用固定值。HG008 的分布只當實驗設定，不當預設（「單一資料校正的設定不當預設」）。

## 4. SNV 位置：要的是「不同 clone 之間」的 SNV 對

- **密度差很多：** HG008 有約 5,800 個 SNV 在 1.1 Gb 的 1+1 區（約 5.3 個／Mb）；diplosim 預設 1,000 個 SNV 撒在 3.1 Gb（約 0.3 個／Mb），稀了約 16 倍〔推論〕。
- **均勻撒點時，某一對 clone 之間、同 HP 的 SNV 對：** 1,000 個 SNV 只有約 0.26 對；2,600 個約 1.7 對〔模擬〕`evidence/q45.py`。
- **成簇突變（kataegis）幫不上：** 一群是一次事件，落在同一個 clone、同一條 HP〔論文〕Nik-Zainal 2012 Cell PMID 22608084；Bergstrom 2022 Nature PMID 35140399。它增加的是同一 clone 內的 SNV 對，不是不同 clone 之間的〔推論〕。
- **HG008 的密集區多半不是真的：** 沒有標籤的密集區不是 APOBEC 型，normal 樣本也常有 alt，比較像旁系同源序列造成的假訊號〔實測〕`evidence/t2_normal_alt.txt`、〔推論〕。
- **建議的參數：** 一個「SNV 密度」旋鈕（每 Mb 幾個 SNV，或等效的基因組長度），讓 clone 之間的 SNV 對數量接近真實資料。成簇突變之後再加，而且要綁在同一 clone、同一 HP。

| 方案 | 做法 | 傾向 |
|---|---|---|
| 甲：均勻（現狀） | 不改 | 當對照 |
| 乙：SNV 密度旋鈕 | 位置仍均勻，但可設每 Mb 幾個 SNV | **先做** |
| 丙：均勻＋成簇成分 | 參數：成簇比例（文獻全癌種約 3.7%）、每群 4–50 個、群內間距約 100–1,000 bp | 之後；對分開相近的群幫助小 |

## 5. 評分方案（haploclone，要決定）

| 方案 | 做法 | 優點 | 風險 |

| 甲：現行逐對 Beta | 不改 | 和 PhyClone 擴充原設計一致 | CCF 差 ≤ 0.05 的祖先／子代分不開；HG008 偏向同一群 |

| 丙：乙＋從 01 估錯誤率 | 用 01 read 的比例估 eps | 對錯誤比較穩 | 實作較多；還沒測 |

## 6. 建議順序

1. 選評分方案，並先在 HG008 上驗證（不用模擬，資料已有）。
2. diplosim 加「只模擬 SNV 對」＋ read 長度分布＋ SNV 密度旋鈕。
3. 一次改一個參數掃描：CCF 差 {0.02, 0.05, 0.1, 0.2}、purity {0.6, 0.9}、每條 HP 深度 15–60×、SNV 密度（含 HG008 等級）。用群數與樹形評分，不用 SNV 對的分數。

## 7. 限制

- 共現在 11-04 從需求表拿掉；要做等於改那次決定。
- 正在跑的 HG008 C4 實驗（`../2026-11-15_hg008_c4_rebuild/`）用的是現行評分，而且包含可疑的密集區。依 §1，預期 L111 分不出來；它的結果當對照。
