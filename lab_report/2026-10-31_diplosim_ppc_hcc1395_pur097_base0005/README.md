# diplosim PPC：`mistag_rate`、`base_error` 各自的效果（2026-10-31）

問題：之前兩個錯誤率一起調。各自解決了哪些統計量？

四組都設 `--prop-pos-lost 0.45 --min-tumour-purity 0.97 --max-tumour-purity 0.97`：
無錯誤（`..._pur097_noerr/`）、只開 `--mistag-rate 0.005`（`..._pur097_mistag0005/`）、只開 `--base-error 0.005`（本目錄）、兩個都開（`..._err0005_pur097/`）。

標記：〔實測〕＝本實驗計算；〔推論〕＝本檔推論；〔程式〕＝讀程式得到。

## 1. 結論

- **兩個參數都只對「alt 分在兩條 HP」有明顯作用，兩者的效果大致相加。** 無錯誤 0 → 只開 mistag 0.008 → 只開 base 0.017 → 兩個都開 0.026（真實 0.028）〔實測〕。
- **`base_error` 的貢獻反而比較大。** 另一條 HP 上的 ref read 被讀成 alt，就會算成 alt 分在兩條 HP。alt 少的 subclonal SNV 只要多 1 條這種 read，就會超過 10% 的門檻〔程式＋推論〕。
- **VAF 90% 分位兩個參數都沒有作用。** 無錯誤時已經是 0.958，靠的是 purity 0.97〔實測〕。
- `mistag_rate` 讓 minor HP < 0.1 的位點稍微變少（0.452 → 0.446），因為 LOH 區多了被標錯的 read〔實測＋推論〕。`base_error` 讓「SNV 在 depth 較少那條 HP」稍微接近（0.261 → 0.255）〔實測〕。兩者的變化都小於模擬區間的寬度。
- 13 項平均相對差距：無錯誤 0.389、mistag 0.368、base 0.344、兩個都開 0.319〔實測〕。

## 3. 限制

- 錯誤率 0.005 是看 HCC1395 選的，只當實驗設定。
- 「alt 分在兩條 HP」的門檻（另一條 HP 的 alt ≥ 10%）會影響兩個參數的相對貢獻〔推論〕。
