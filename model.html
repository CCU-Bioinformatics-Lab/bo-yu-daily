HCC1395 · MODEL ARCHITECTURE

Tumor Evolutionary Tree Model

用每個 SNV 的 bulk reads、ASCAT copy number、purity 與模型內部 multiplicity，評估哪些 clone tree 能合理解釋目前的 bulk 定序資料；HP evidence 保留作補充資訊。

Model = 合理性評分規則；Inference = 搜尋合理狀態的方法

一眼看懂主流程

模型把可觀察的資料，轉成對候選腫瘤演化樹的 posterior 支持。

SNV observations

模型看到的證據，不是模型自己猜出的結果。

  • bulk reads
  • ASCAT CN + rho_ASCAT
  • HP counts：補充／QC
→

Model scoring

計算某個 clone state 是否能解釋目前的 reads。

ALT ~ Binomial(total_reads, r)
→

Latent clone tree

看不見的拓樸、SNV assignment 與 clone mass。

  • T：tree
  • zᵢ：SNV → clone
→

Posterior outputs

輸出候選結果與每個 SNV 的不確定性。

  • tree + CCF／phi
  • multiplicity posterior

模型實際讀取的資料

Reads

ref_readsalt_readstotal_reads

同一 SNV 的 REF／ALT 觀測，且 total_reads = ref_reads + alt_reads。

HP evidence

hp1_1_*hp2_1_*

HP1-1／HP2-1 是 bulk reads 的子集合，現在只作補充資訊、QC 與未來 Model B。

CN + purity

major_cnminor_cnrho_ASCAT=0.99

CN 決定 copy context；purity 固定反映 normal contamination 比例。

data.md 最終輸入怎麼進到 model.md

把 data.md 的固定輸入表想成一張點名表：每一列是一個 SNV，模型依序讀取，再放進整體腫瘤演化樹分析。

1. 一列 SNV 資料

REF 34 / ALT 11 / 總深度 45
HP reads / major CN 3 / minor CN 1
purity 0.99 / 可納入

這一列就是模型要看的單一突變位置。

→

2. 變成模型資料卡

程式把這列分成幾種證據：

  • REF／ALT reads
  • CN 與 purity
  • HP counts：補充資訊

只有標記為「可納入」的 SNV 會繼續往下走。

→

3. 模型補上看不見的資訊

模型根據 CN 猜測突變可能帶幾份 copy，也嘗試把 SNV 放到不同 clone。

接著估計每個 clone 包含多少腫瘤細胞，這個比例叫 CCF。

→

4. 和真實 reads 比較

模型根據 purity、CN、CCF 和 latent multiplicity，預測應該看到多少 ALT。

預測越像實際看到的 reads，這個候選狀態就越合理。

→

5. 找答案並輸出

推理演算法反覆嘗試不同的樹和 SNV 所屬 clone。

  • 候選演化樹
  • CCF 與 SNV 分配
  • multiplicity posterior
只做 QC／追蹤

cnv_status、segment_id、loh_state、cnv_confidence 等補充欄位不參與模型計算；它們只協助排除問題資料或追蹤來源。

重要邊界

PS 不直接進模型；它在上游協助產生 HP reads。HP reads 是 bulk reads 的一部分，不是第二批獨立資料。

模型裡面自己推導的量

Clone state

T 決定誰是 parent／child；zᵢ 把每個 SNV 放到某個 clone；eta 是 local mass。

eta + tree → phi / CCF
Multiplicity state

ASCAT major/minor CN 先建立可行候選；bulk reads、purity 與 CCF 再共同計算候選的 posterior responsibility。

CN → candidates → likelihood marginalization

Multiplicity 怎麼走？

ASCAT CN

major_cn／minor_cn 提供可能的 copy 數範圍。

→

C++ loader

在記憶體內建立 Mᵢ 候選，不讀外部 multiplicity table。

→

Posterior

Mᵢ 在 likelihood 中被邊際化，輸出 multiplicity_posterior.tsv.gz。

Model 與 inference algorithm 的分工

MODEL

likelihood · prior · latent variables
INFERENCE_ALGO

在很多候選狀態中搜尋或抽樣，探索 T、zᵢ、eta。

目前方法：MCMC；細節見 inference_algo.md

PS 與 normal contamination 的位置

PS block → HP counts

PS 是上游 phase evidence，協助產生 HP1-1／HP2-1 counts；原始 PS 不直接進 C++ likelihood，也不是 clone label 或 tree edge。

rho_ASCAT → emission

rho_ASCAT=0.99 固定處理 normal contamination；normal cells 不是模型重新推導出來的 clone node。

輸出與限制

Candidate tree

候選腫瘤演化樹與 topology。

Clone assignment + CCF

SNV 所屬 clone 與 phi／CCF 的 median、95% interval。

Topology support

label-invariant edge support summary。

Multiplicity posterior

每個 SNV 的 latent multiplicity 支持度。

解讀邊界： 這是 bulk-data-supported candidate tree，不是 single-cell lineage truth；finite K 不等於真實 clone 數，HP1-1／HP2-1 也不是 clone label。
