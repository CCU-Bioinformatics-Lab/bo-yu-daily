腫瘤演化樹模型

像用散落的家族照片重建家譜：模型綜合所有 SNV 線索，評估哪一種 clone 分組與分支關係最能解釋目前的 bulk 定序資料。

目前是診斷用候選模型；通過完整驗證後才能作正式結果解讀

一眼看懂：從資料到候選樹

推理演算法負責提出不同答案，模型負責替每個答案打分數。

固定資料 vs. 系統自動嘗試

這個分界最重要：copy number 與 purity 是輸入；樹、分組與比例才是系統要尋找的答案。

模型收到的固定資料

REF／ALT reads該 SNV 實際看到多少 reference 與 alternate reads。
ASCAT copy number該位置有多少染色體拷貝，包含 major、minor 與 total CN。
ASCAT purity = 0.99樣本中腫瘤成分的固定校正值，不由模型重新猜。
可納入狀態只有通過資料檢查的 SNV 才會參與評分。

系統反覆嘗試的答案

樹怎麼連固定容量的候選 clone 要形成哪種親子分支。
SNV 放在哪個 clone把每個突變分配到最能解釋 reads 的位置。
各 clone 的比例綜合所有 SNV 估計 clone 比例，再由整棵樹推導 CCF。
突變拷貝數multiplicity 表示突變可能出現在幾份染色體拷貝上，由 CN 限制後在模型內比較。

樹與 CCF 是什麼？

只有一個 tumor founder

所有 tumor clones 都從同一個 C1 分支往下發展；structural root 不直接分出兩個 tumor founders。

CCF 不是單一 VAF 直接換算

模型綜合所有 SNV、clone 比例與整棵樹，計算某個 clone 分支及其後代占全部腫瘤細胞的比例。

multiplicity 不需要外部欄位

系統先用 ASCAT CN 限制可能值，再根據 reads、purity 與候選 clone 比例比較哪個值更合理。
